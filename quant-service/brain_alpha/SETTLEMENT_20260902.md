# 2026-09-02 結算量測 — 判讀表

問題：`score` 卡在 10000.0，兩種解釋處置相反。
- **每天剛好吃滿上限**（5 天 × 2,000）→ 繼續交 alpha 仍有邊際價值
- **分數在 10,000 封頂** → 金牌之後再交一條都是 0 分，整條產線邊際價值為零

不必再交任何東西就能得到答案：09-01 交的兩條會在今天結算進榜。

## 四個原始值
一律取 `/users/self/competitions` → `results[id==challenge].leaderboard` 的：
`score` / `rank` / `alphas` / `level`

`alphas` 是唯一的區分變數（brain_auto.py:680）。沒有它，`score` 不動會同時符合兩種解釋。

## 判讀
| 讀到 | 判 |
|---|---|
| `score` 12000 | 每日上限吃滿 → 繼續交有邊際價值 |

| 任何一個問不到 | 寫「問不到 HTTP xxx」，**不寫看起來正常的數字、不沿用前一筆** |
