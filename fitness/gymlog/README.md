# GymLog 健身記錄 App

離線健身重量記錄 PWA。深色 UI、繁體中文、零外部依賴，資料存手機 localStorage。

## 裝到 iPhone（只需做一次）

1. 電腦上雙擊 **`啟動健身App.bat`**，等它印出 `https://xxxx.trycloudflare.com` 網址。
2. iPhone 用 **Safari** 開那個網址（打字或傳給自己）。
3. 點 Safari 的 **分享 → 加入主畫面**，完成。
4. 主畫面會出現金色槓鈴的 GymLog 圖示。**開一次讓它載入完**，之後健身房沒網路也能用，電腦也不用開機。
5. 裝完可以關掉電腦上的視窗（bat 視窗按 Ctrl+C 關閉，另一個 GymLogServer 小視窗也關掉）。

## 功能

- **首頁**：五天課表（Upper / Lower / Pull / Push / Leg&abs），顯示每天上次練的時間，點了開始訓練。
- **訓練模式**：每組記重量＋次數打勾；自動預填上次的數字（要進步只要按 +2.5）；kg/lbs 每個動作獨立切換；打勾後自動跳組間休息計時器；訓練到一半關掉 App 再開會自動回到進度。
- **歷史**：每個動作的進步曲線（混用 kg/lbs 會統一換算成 kg 畫圖）＋完整紀錄。
- **課表**：動作增刪改、排序、新增訓練日；「複製整週」可以快速建第三週（力量）再微調。
- **設定**：匯出／匯入 JSON 備份、休息計時器開關、全部重設。

## 備份（重要）

資料只存在手機裡。**設定 → 匯出備份**會下載一個 JSON 檔，存到「檔案」App 或 iCloud。
超過 14 天沒備份，首頁會出現提醒。

## 改版／更新流程

> 開發注意：改了任何檔案，`sw.js` 開頭的 `VER` 版本號都要 +1，否則 service worker 的 cache-first 會讓已安裝的瀏覽器永遠停在舊版。

重跑 `啟動健身App.bat` 會拿到**新的網址**＝新的資料空間，舊資料不會自己跟過去：

1. 舊 App 裡先 **匯出備份**。
2. 刪掉主畫面舊圖示，用新網址重新「加入主畫面」。
3. 新 App 裡 **匯入備份**。

## 檔案

| 檔案 | 用途 |
|------|------|
| `index.html` | 主程式（全部功能都在這一支） |
| `sw.js` | service worker，讓 App 離線可開 |
| `manifest.json` / `icon*.png` | PWA 名稱與圖示 |
| `啟動健身App.bat` | 一鍵起本機伺服器＋cloudflared https 網址（僅安裝/更新時需要） |
