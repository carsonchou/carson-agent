# 副頻道轉型方向:實測結果與排序(2026-09-09)

Carson 09-09:「副頻道可以自己看看熱門趨勢去轉型」。本檔是需求實測的結論。
起點狀態見 `docs/ch3-revival-state-2026-09-09.md`(1 訂閱 / 生涯觀看分鐘 32 / 長片零分發)。

## 儀器:量的是「可攻性」不是「搜尋量」

**YouTube 不對外給任何 query 的絕對搜尋量,查不到,不用估計值冒充。**
實際量的是:**小頻道(<15 萬訂閱)能不能靠這個 query 拿到遠超自身觸及的觀看**
(判準:v/s ≥3 倍**且** ≥5 萬觀看)。理由:第一頁最高觀看反映的是**頻道觸及**,
但「2.9 萬訂閱拿到 306 萬觀看」沒辦法用觸及解釋。

偏誤方向:v/s 用**今天**的訂閱數,而爆片會把訂閱推上去 ⇒ 倍率是**低估**,不製造假陽性。
儀器已用 ColdFusion 5.24M / Psych2Go 13.1M / TEDx 44.6M / Veritasium 21.2M 四個已知值校準
(第一版把側欄推薦頻道的數字當成本頻道,已修)。

🔴 已知限制:①每 query 只取近一年前 10 名,樣本小 ②近期零供給的 query(如 `why does he pull away`)
**分不出「需求死了」和「有缺口」** ③量的是相對可攻性不是絕對需求。

---

## 🔴 最重要的結論不是關於題材,是關於**姿態**

三組獨立資料,同方向:

| 資料點 | 方法(「怎麼做到 X」) | 裁決(「這說法成不成立」) |
|---|---|---|
| dopamine detox | HustleCore 29,000 訂閱 → **3,061,295**(105.6×) | **Psych2Go 13,100,000 訂閱 → 52,885**(它訂閱數的 0.4%) |
| 學習與記憶 | 「Memorize Anything So Fast It's Almost Unfair」等,全部是方法 | 「有人真的有照相式記憶嗎」1.4× |
| 裁決型 query `memory palace does it work` | — | 天花板 1.4×(最高的 42.6× 是 178 訂閱拿 7,580 觀看=雜訊) |

**Psych2Go 那一列最重,它用 1,310 萬訂閱做了和 ch3 一模一樣的片(「是解方還是騙局?」),拿到 0.4%。**
⇒ ch3 整個身分(「They Ran It Again」=我們把那個研究重跑了)正好是市場最不買單的那一半。
可轉移的是**能力**(查證據、做圖表、下判斷),要換掉的是**姿態**——從「這說法不成立」換成「什麼有效,證據在這裡」。

⚠️ 信心等級:三組資料、單一排序、樣本小,**這是本輪最佳讀法不是定論**。
下面的共用測試會直接測它,不需另外設計實驗。

## 活區與方向排序

| 排序 | 方向 | 證據 | 致命問題 |
|---|---|---|---|
| **1** | **學習與記憶方法** | `how to remember what i read` 5 個小頻道 **4 勝出** | 勝出片靠**極強承諾**,而學習科學的誠實結論是「有效但慢、效果中等」 |
| **2** | **自我提升宣稱查證** | dopamine detox 3/3 勝出、105.6× | 需求可能要的是承諾不是裁決(見上) |
| 3 | 實用社交心理 | `how to make people like you` **4/4 勝出**、31.7×;轉移率最高(PsychToons 就是動畫無臉心理學頻道) | 🔴 **贏的打法會撞紅線** |
| 4 | 依附與感情 | 2 勝出、17.1× | 🔴 這區靠**人格驅動**(心理師本人出鏡),無臉在這裡最致命 |
| 5 | 「X 到底有沒有用」消費裁決 | n=1(duolingo 54.2×) | 另兩個同型 query 都 0 勝出;且唯一樣本可能是 Duolingo 本身的名氣 |

🔴 **方向 3 的紅線細節**:`dark psychology tricks` 的勝出者是 **7,910 / 8,200 訂閱**的頻道,
標題「99% Success」「Should Be Illegal」—— 典型模板化量產,正是 YouTube inauthentic 政策點名的樣態
(memory `yt-inauthentic-template-risk-2026-08`)。**ch3 用現有量產管線進這區,成功本身就會把頻道推向 YPP 風險。**
要做就得低產量高單支投入,而那正好放棄 ch3 唯一的規模優勢。

📌 方向 2 的精準度提醒:同一題材,**「方法」框架活、「抱怨」框架死** ——
`why do i forget things so quickly` 是 **0 勝出**。選題要落在方法側。

## ⚠️ 總督導複驗時的兩點分歧(兩份都留,不要挑一個)

1. **`how to remember what i read` 的強度我算得比它弱**:它報最佳 v/s 27.0、勝出中位數 1,009,627;
   我同日拉近一年前 12 名得最佳 **12.3×**、中位數約 **57 萬**。結果集不同(排序/窗口),
   **兩個都不是權威值**,要用時請重跑並記下取樣參數。
2. 🔴 **那組有 ESL 混淆,最終版沒有納入**:我拉到的 4 個勝出裡有 2 個是**英語學習頻道**
   (VUS - Learning English 49,900→401,104、English With Ethan 138,000→496,508,標題掛 Learn English / Graded Reader)
   ⇒ 這個 query 同時吃「想記住讀過的」和「想學英文」兩種需求,**後者我們接不到**;扣掉後強度掉一半。
   ⇒ 通則:**篩掉大頻道之後還要再問一次「這些小頻道是不是在服務另一個需求」**。
   v/s 高只證明不是觸及,**不證明是同一個需求**。
3. 📌 同一句標題「How to Rewire Your Brain to Enjoy Discipline」在同一頁出現三次,
   結果 3,061,295 / 764,856 / **17,311**(最後那支 141,000 訂閱)⇒ **同題同標題差 177 倍**。
   **這支儀器能說哪裡有需求,不能說我們拿不拿得到。不要把 105.6× 當預期值。**

## 共用測試:6 支同時判定方向 1+2 與「姿態」那題

- **3 支裁決框架**(dopamine detox / brain rot / learning styles:「這說法撐不撐得住」)
- **3 支方法框架**(how to remember what you read / active recall / spaced repetition:「怎麼做」)
- 判成功:14 天內 **≥3 支各 ≥500 engaged views**,且搜尋+推薦合計 **≥25% 觀看分鐘**
  (⚠️ 用觀看分鐘不要用觀看數 —— 主頻道實測有效觀看只有 30.9%,用觀看數會高估三倍)
- 判失敗:6 支觀看中位數 <100,或搜尋來源 <10%
- 基準乾淨:ch3 現況 131/141 來自 Shorts feed、**搜尋 ≈ 0** ⇒ 搜尋佔比動了就是真訊號
- **附帶產出**:哪一臂贏,直接回答「觀眾要承諾還是要裁決」

🔴 **總督導加一條:兩臂的通過數要各自事前登記,不能只登記合計。**
現行「≥3 支通過」在 3+3 設計下,可能完全由方法臂達成而裁決臂全滅 ——
那種結果對「要不要繼續」是通過,對「保不保得住現有定位」是否決。**兩個問題要各自有答案。**
📌 3+3 平衡設計犧牲了一點成功機率(裁決臂已有負面實據),換到的是姿態那題的乾淨答案。
這個取捨我接受,但要寫明白,不要事後解釋成「我們本來就知道」。
