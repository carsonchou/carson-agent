## 判準

**沿用 `4583c2ca` 的 A / B / C 三類,一個字不改。** 督導指定的問句
「這個數字在該檔自己的事實池裡有沒有對應」對應到:

| 類 | 定義 |
|---|---|
| **A** | 該片事實卡對**同一件事**給出**不同的值**(要指得出是哪條 fact、哪個值)⇒ **真的講錯** |
| **B** | 數字與事實卡**一致**,只是守門認不出(成數重述 / 同句可推導 / 單位換算 / 池建法漏掉)⇒ **誤標** |
| **C** | 事實卡對這件事**沒有可比對條目**且**沒有矛盾**(對照標的 / 不同期間 / 跨股統計)⇒ **無法判定** |

片層彙總:任一宣稱判 A → 該片算 **真陽性**;全部 B → **誤標**;其餘 → **無法判定**。

## 事前登記的預測(我的)

理由:前兩輪的誤標主力是**成數/整十數描述回撤**(`9d6acf1e` 已修)與**crash 事實撈不到**
(`5237734c` 已修)—— 那兩類佔了第一輪 4/10 與第二輪 4/10 的全部誤標。
