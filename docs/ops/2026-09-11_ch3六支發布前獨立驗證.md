## 6. 可逆性

**答:可以撤下,但撤不掉;而且「撤下來了」這句話要等數小時才能講。**

- **沒有刪除工具。** 全 `ch3_lab/` 沒有任何一支呼叫 `videos().delete`。撤回 = 改
  privacyStatus,不是移除。已發生的觀看、已進 Shorts feed 的曝光都收不回來。
- 現成工具是 `ch3_lab/unlist_one.py`,**一次一支**、要手打 videoId:
  `python unlist_one.py --id <VID> --to private --apply`。
  它做對了三件事:頻道白名單、`status` 先讀回再只換一欄、改完回讀。
  配額 52/支 ⇒ 六支 **312 unit**。
- 🔴 **回讀的尺度是小時不是秒。** 已知案例(`docs/ch3_recurrence_test_prereg_2026-09-09.md:176`
  / memory `yt-readback-stale-cache`):21 支改 private,30 秒後回讀 9/9 是 private,
  **50 分鐘後其中兩支自己變回 public**。
  ⇒ 撤回之後**不能當場宣布成功**,要隔數小時、換獨立儀器、帶陰性對照再驗一次。
- ⇒ **「先發看看,不行再撤」不是一個真的退路。** 撤回會遲、會漏、會靜默失敗,
  而且撤回本身也是一次紅線動作(`videos.update` 動已對外的東西)。

### 這個方法證不到什麼

1. **證不到 Google 端會不會接受。** 送出去之後 API 回 200 還是 403、

### 🔴 一個我原本以為要打問號、後來用歷史證掉的疑點:scope

`svc()` 向 `Credentials.from_authorized_user_file()` 傳入
`youtube.upload + force-ssl + readonly` **三個** scope,而 `token_manage.json` 檔裡
只有 **force-ssl + readonly**。傳入的 scopes 會**覆蓋**檔裡的,refresh 時就會向
Google 要一個沒被授權的 scope。

- 【碼】google-auth **2.50.0**(本機實裝版)`google/oauth2/credentials.py:452-466`:
  requested 但沒 granted 的 scope 只 `_LOGGER.warning`,**不丟例外**。所以不會中止。
- 官方文件說 `videos.insert` 接受 `youtube.upload / youtube / **youtube.force-ssl** /
  youtubepartner` ⇒ 光靠 force-ssl 應該就夠。**但這是靜態推論。**
- 【史】**把它變成事實的證據**:`uploaded_shorts.json` 有 38 筆,其中 7 筆是
  `reel_*`,最新一筆 `reel_mozart_effect` 的帳本 mtime 是 **09-04 09:19**;
  而 `token_manage.json` 的 mtime 是 **09-03 09:30**、之後沒再被寫過
  ⇒ 09-04 那次成功上傳時,那個檔的 scope 組合**就是現在這一組**。
  ⇒ **force-ssl 單獨足以做 `videos.insert`,是跑出來的,不是讀出來的。**

## 結論

# 有條件可以發

發布動作本身是乾淨的:**頻道對(且有一道跑起來會擋的白名單,陰性+陽性對照都過)、
privacyStatus 寫死 public 無覆寫路徑、兩本配額帳確實分開且水位有兩倍餘裕、
說明欄零洩漏、DOI 一個不漏、寫入不會碰到主頻道的任何目錄或帳本。**

三個條件:

1. 🔴 **先修「The papers are linked above.」這句話,或改掉那句話。**
   送出去的是裸 `doi:` 字串,YouTube 不會 linkify ⇒ 說明欄裡有一句對觀眾為假的話。
   改成 `https://doi.org/<doi>` 是最小修法(動 `cites_for()` 一行);
   若決定不改,就要把那句改成描述現況的講法。
   **這條是我唯一要求發布前處理的。** 理由:這條線唯一的資產是「查得到」。

2. **用 `--only` 明確指名六個 key,不要靠 `--limit 6` 的預設挑片。**
   這次 `--limit 6` 恰好挑對,是因為 `reel_stanford_prison` 被閘門擋下之後候補遞補
   —— 那是**閘門結果決定的**,不是我驗過的那組決定的。程式自己的註解就記過
   同一個坑(「驗過的和發出去的必須是同一組,而預設不保證這件事」)。

3. **事先講好撤回方案,並接受「撤不掉」。**
   沒有刪除工具;撤回 = `unlist_one.py` 一支一支改 privacyStatus(312 unit);
   回讀要隔數小時再驗(已知 50 分鐘後會自己變回 public)。
   ⇒ 不要把「不行再撤」當退路來降低這次的決策門檻。

另外提醒兩件不影響放行的事:`--dry-run` 會連網(唯讀,約 1 unit),
它印的「未連網」是錯的;dry-run 印的配額估算 9,636 沒算縮圖的 300,實際 ≈9,938。
