## 方法論(唯一會隨 context 消失的東西)

1. **「沒有 R」和「我沒查到 R」是兩件事** —— 我把後者報成前者,差一點把一個可回答的問題
   登記成「無法回答」。搜尋順序:**先 ls 資料目錄,再 grep 程式碼**。
2. **grep 零命中不是證據。** 「我 grep 過了」只證明查過那幾個動詞。
   **錯的否定比錯的肯定危險一級**:錯的肯定會被下一個人撞到而修正,
   錯的否定讓下一個人**根本不走那條路**。
3. **反駁一個數字 → 升級成反駁一種機制。** 前者永遠可以被下一個數字再挑戰。
   實例:滾動清理**數學上必須刪掉年齡排序的連續前綴** ⇒ 證明「不單調」就排除所有門檻。
4. **量了不等於量對。** 「我有數字」比「我有推論」更容易讓人不再檢查
   (WorkingSet vs PrivateMemorySize64 那次)。
5. **我們的工作只有落到磁碟上的部分存在**(memory `only-what-lands-on-disk-exists`)。
   關窗格前先問「它手上有沒有只活在逐字稿裡的東西」。
6. **改活的正式機檔一律 tmp → 讀回比對 → `os.replace`**,並先記一個可機械比對的不變量。
   ⚠️ 用 **local_cron 自己的 `parse_jobs()`** 當不變量,不要用自己寫的 regex。
7. **不要把要保留原樣的文字交給 shell 解析** —— 今天被 `printf` 的 `%` 和反引號
   各咬過一次以上。長文字一律寫檔案再餵。
