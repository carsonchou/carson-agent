## 二、真正的問題

**不是戰線太多，是唯一在跑的那條線需要兩道閘門同時開才會付錢。**

YPP 要求（政策事實）：
1. 近 12 個月 **4,000 小時**觀看時數
2. **1,000 位訂閱者**

memory 記錄的現況（⚠️ 數字互相衝突且都是 1~3 週前的，我**沒有現查**——配額本來就結構性超支，不值得為這個再燒）：
- `yt-search-capture-engine-2026-08`：月時數 **13 → 695**，上月佔全年 83%（→ 年累計推算約 837 小時）
- `yt-ypp-gap-anatomy-2026-08`：430/4000，且「**訂閱到 1000 也只有 1112 小時 → 差 14.4 倍外部觸及**」
- `yt-subscriber-feed-pollution-2026-08`：訂閱者約 **157** 位

**兩份 memory 對時數的說法不一致**（430 那份被後者標為「已推翻」）。真值我不知道，這本身就是個問題：**你最重要的一條線，進度數字沒有可信的單一來源。**

但無論用哪個數字，結構是一樣的：
- 時數閘門**正在改善**（13→695/月是真的加速）
- 訂閱閘門**才是卡點**：157 → 1,000 還差 843 位，而長片訂閱轉化率是 0.46~0.50%

## 三、砍哪些（按確定性排序）

### ✅ 已執行 2026-08-25 — 封存：`cs2_arb`
不是「暫緩」，是**已經被自己的實測證偽**。memory 結論：現金/Steam = 0.56~0.66，路線 A 需 23.6% 折扣而合法只有 3~5% → 結構上只能靠灰貨源。
**這個結論不會因為再試一次而改變。** 留著只會偶爾誘惑你回去看一眼。

### ✅ 已執行 2026-08-25 — 封存：`ch3_lab`

**決定性證據**：今天(08-25)全 repo 掃描，`.claude-flow` 的 session 暫存檔以外，
**唯一被修改過的專案檔案全部在 `ch3_lab`**——
`ep001.mp4`、`ep001_voice.wav`、5 段 `narr_*.txt`、5 段 `seg_*.wav`、`render_ep001.py`、
`facts/ep001_ego_depletion.json`。

主題是 `ego_depletion`（心理學），對應 memory `yt-niche-scan-tool-2026-08` 掃出的
「TW 前三利基＝心理學 / AI自製系統 / AI工具」。

也就是說：**今天你親手投入的產能，100% 進了第三個還沒開的頻道。**

**時序不對**：
- 主頻道 967 支還沒過 YPP
- ch2 才剛首發
- 然後你開了第三個

在第一個頻道還沒證明模式能過閘門之前開第三個，是拿唯一的產能去攤平在三個都沒過門檻的東西上。
**ep001 已經產出來了就留著當素材，但停止投入。**

**但要改一件事：不要再把它當現金計畫。** 它是資產累積，不是收入。兩道閘門都還沒過，過了之後 YPP 分潤也需要時間爬。
