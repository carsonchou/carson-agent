## 三、值域全掃(問「整個百分比空間有多少是放行的」)

同一句型換值,`0.1 ~ 100.0` 每 0.1 一格:

| 句型 | 放行 |
|---|---|
| 一般績效句「勝率是 X%」 | **1000/1000 = 100.0%** |
| 假掛名「回測顯示,年化報酬率是 X%」 | **1000/1000 = 100.0%** |
| 一般績效句「二十年總報酬是 X%」 | **1000/1000 = 100.0%** |
| 比較結果句「比大盤高出 X%」 | 0/1000 = 0.0%(全擋) |

大值域(一般績效句):`101~2000` step 1 → **100%** 放行;`2000~10000` step 10 → **100%** 放行;
`10000~60000` step 100 → 34.6% 放行(飽和到此為止)。

⚠️ **這條要限定句型,不是全稱**(獨立驗證員 09-08 補正):**假掛名句**在 `2000~10000` 只有
**731/801 = 91.3%** 放行(4220 / 5160 / 5680 / 997 等值被擋)。
⇒ 「0.1~10,000 一律 100% 放行」只在**一般績效句**上為真;實務區間(≤2000%)兩種句型都是 100%。

⚠️ **整十數(30/40/…/90)那條 2026-07-14 補的嚴容差規則,現在也 100% 放行** ——
它當年擋得住「勝率 90」,今天擋不住了。

## 四、述詞層(總督導指名的 `_sourced_unit`)

`_sourced_unit(v, "X%", fact_pool(), strict)`,v 掃 0.1~100.0:

| strict | 判「有憑據」 |
|---|---|
| `False`(寬容差 ±1.0 / 2%) | 1000/1000 = **100.0%** |
| `True`(嚴容差 ±0.25 / 0.5%) | 1000/1000 = **100.0%** |

**連嚴容差都鋪滿了。** 這一格重要,因為 07-14 的整個補強設計是「懷疑時升級到嚴容差」——
那個逃生梯現在通往同一個地方。

## 五、根因:池飽和,而收窄池從沒被接上

全域 `fact_pool()` = **42,134** 個數字;其中 `pct` 子池 = **27,616** 個。
27,616 個數字撒在 0~100 之間,嚴容差 ±0.25 就足以**完全鋪滿**該區間。
⇒ 這不是判準寫錯,是**池大到讓「查得到憑據」這件事失去資訊量**。

`fact_pool_for(slug)`(`fact_source_guard.py:365`)正是 2026-08-27 為這個病寫的收窄池,
它的 docstring 白紙黑字記著「隨機三位數 → 100% 找得到憑據」。

🔴 **但它沒有任何產線呼叫端。** 全 repo grep `fact_pool_for` 只有三處命中:
定義本身一處、`produce_batch.py:4579/4581` 兩處**註解**。
`daily_publish.py:581` 傳進閘門的是 `fsg.fact_pool()` —— 全域池。

⇒ **「收窄池已經寫好了」不等於「收窄池在用」。**(同一族:「閘門已上線」≠「已經擋住了」。)

## 十三、🔴 B/C 不是單調收緊 —— 今天的「中性」是池飽和的副產品(獨立驗證,2026-09-08)

### ① 🔴 B 和 C 各自都能把「擋」變成「放行」——我以為的單調性不存在

**C(受控池 `{25.0, 70.0}`)**

### ② B 的對照物會把「被比較方自己的數字」吞進來 ⇒ 誤擋(已修)

驗證員給的四句,**舊=放行、一修後=擋**(我逐句重跑,4/4 一致):

```
它落後大盤指數報酬是100%。      這檔股票落後加權指數報酬31%。
這檔的總報酬領先0050同期報酬50%。  我們的策略贏過大盤同期年化12%。
```

機制:對照物吞掉了**被比較方自己的績效值** ⇒ 那個數字是**操作數**不是關係值
(「0050 同期報酬 50%」講的是 0050,不是差距)。一修的收斂①「對照物不得含『的』」
擋不到它們 —— 它們本來就沒有「的」。

**二修**:對照物不得含**指標名詞**(報酬/年化/勝率/回撤/殖利率/績效/配息/股利/營收/毛利/淨利/
EPS/每股/夏普…)也不得含「是」。有指標名詞時,數字歸屬於那個指標,語意上本來就是操作數。
- 四句誤擋 → **全部回到放行** ✅
- B 的原始目標(落後大盤 31%、高出大盤與 0050 整整 31%、輸給加權指數 12.5%、少賺台積電 58%)

- 91 支真實候選:擋片 **20**、pct 抽出 **2,824**、pct 被擋 **54** —— 與二修前一字不差
- `--regress` 仍為 **0/5**
