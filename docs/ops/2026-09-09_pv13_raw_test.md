## 🔴 但對手解釋(雜訊衰減)被推翻了

事前指認的混淆是「raw 只是比較吵,所以跟什麼都比較不像」。**資料往反方向走:**

- **三組 raw 沒有比較低的,正好是 Sharpe 最低的三組**(0.86 / 0.91 / 1.24),
  而它們的 raw corr 是 **0.7818 / 0.7821 / 0.7966 —— 全場最高**。
  雜訊衰減預測「越吵越不像」,實測是**最吵的最像**。
- 判別點那組(raw 的 Sharpe **高於**自己的 per_px/per_cap)raw 仍然最低 **0.4501 vs 0.79**。
- `r(ΔSharpe, Δcorr) = −0.391`:ΔSharpe 最大的那幾組(+1.24~+1.31)Δcorr 幾乎是 **0**,
  而 Δcorr 大的那幾組 ΔSharpe 只有中等。**不是單調的,方向也跟雜訊解釋相反。**

⇒ **「raw 相關低是因為它比較弱」這個解釋可以排除。**

## 🔴 真正的圖案不是「raw vs 正規化」,是**欄位家族**

把 5 個「raw 明顯較低」和 3 個「raw 沒有較低」分開看,分界線非常乾淨:

| raw 明顯較低(0.40~0.52) | raw 沒有較低(0.78~0.80) |
|---|---|
| `com_rk_au`、`ompetitorgraphrank_hub_rank`、`ustomergraphrank_auth_rank`、`ustomergraphrank_hub_rank`、`ustomergraphrank_page_rank` | `revere_index_cap`、`revere_index_value`、`revere_term_sector_total` |
| **全部是圖中心性排名**(rank / hub / auth / page) | **全部是 revere 的 index / sector 聚合** |

post-hoc 那 21 組同向:`pv13_com_page_rank`(圖排名)raw 0.4135 vs per_* 0.79~0.81;
而 `revere_company_total` / `revere_level` / `revere_parent` / `revere_term`(sector 聚合)
raw 與 per_* 幾乎一樣(0.51~0.57)。

⇒ **正規化的效果取決於欄位家族**,不是一條普遍規律。這比原假說精確,但它是 **post-hoc 觀察**,
沒有事前登記過,**不可以當成已驗證的結論**。
