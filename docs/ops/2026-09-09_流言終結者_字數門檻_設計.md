## 🔴 三、應變數要改:**觀看分鐘在這題上是被自變數機械決定的**

督導指定用**觀看分鐘**。⚠️ **在這一題上那個口徑會產生假效應:**

```
觀看分鐘 = 觀看數 × 平均觀看時長
而 平均觀看時長 ≤ 片長,片長 ≈ 旁白字數 / 語速
```

⇒ **726 字的片約 3 分鐘,3,500 字的片約 12 分鐘。短旁白的片必然觀看分鐘較低 ——
那是算術,不是品質訊號。** 用觀看分鐘去問「字數夠不夠」等於用自變數去解釋它自己。

**正確的應變數:每次觀看的絕對秒數(平均觀看時長)。**
依據 memory `yt-retention-is-audience-not-content`:
**完播率 vs 片長 r=−0.643 是「1/片長」的影子,比較不同長度一律用絕對秒數。**
⇒ 完播率也不能用(它會系統性偏袒短片),**觀看分鐘會系統性偏袒長片**,兩個都不行。

### 建議的量法(未執行,等督導確認應變數)

| 欄位 | 用途 |
|---|---|
| `averageViewDuration`(秒) | **主應變數** —— 不被片長機械決定 |
| `views` | 分母,一併記 |
| `estimatedMinutesWatched` | 記著參考,**不當判準** |
| 發布日 | 控制暴發日(memory `yt-search-entry-decides-views`:52% 流量來自暴發日) |

母體:「其他」類已發布長片 **22 短 vs 36 長**。
憑證 `token_analytics.json`(`token_manage.json` 缺 scope 會 403);
`dimensions=video` + 分批 `filters=video==`(**200 列硬截斷**)。

## 四、還沒做 / 要先確認的

   而它不含任何資訊。**

   ⇒ 這題最多只能回答「值不值得做一個真的實驗」,不是「門檻該訂多少」。
