# 標題措辭效應能不能用已發布資料回測 —— 可行性(2026-09-09)

副頻道英文線量到**措辭層級**效應(`that actually work` 6/7 勝出、`backed by science` 0/9)。
督導要求:**當假設不當結論**,用主頻道已發布長片回測,預期產出是
「**值不值得做一個真的 A/B**」,不是「該改什麼標題」。答不出來就明寫答不出來。

## 結論(先講):**這題現在答不出來,而卡住的不是 n**

督導點的三個坑裡,**坑① n 太小不成立**,但另外兩件比預期嚴重:

| 坑 | 實測 |
|---|---|
| ① n 太小 | **不成立** —— 分組後 152 / 95 / 64 / 5,前三組都夠 |
| ② 措辭與其他變數糾纏 | 🔴 **比「糾纏」更糟:是完全共線** —— 見下 |
| ③ 跨語言不轉移 | 未測(要先有②的設計才談得到) |

## 🔴 一、措辭與「系列」完全共線,天真設計結構上不成立

已發布長片 **316 支**,按措辭分組(規則先寫再跑):

| 措辭組 | n | 其中「個股體檢」 |
|---|---|---|
| 中性/系列權威 | 152 | **152(100%)** |
| 承諾有效/情緒 | 95 | 57(60%) |
| 中性描述 | 64 | 0(0%) |
| 疑問句 | 5 | 0(0%) |

**「中性/系列權威」這一組 100% 是個股體檢。**
而個股體檢是**量產系列**,發布制度、題材、縮圖模板、產製管線全都跟著它走
(且 memory `yt-search-entry-decides-views`:52% 流量來自暴發日,而量產系列正是暴發日的來源)。

⇒ **拿「中性組 vs 承諾組」跨組比,比到的是「系列 vs 非系列」,不是措辭。**
這不是 n 不夠、也不是「要多控幾個變數」,是**該變數在該組內沒有變異**,設計本身不成立。

### 唯一沒有結構性共線的設計:**在個股體檢內部比**

個股體檢裡措辭**有變異**:**中性 152 vs 承諾有效 57**。
系列、格式、產製管線、發布制度都被固定住 ⇒ **這是唯一能問到措辭的那個切面。**

## 🔴 二、但應變數拿不到,而本機那份是**依應變數本身截斷的**

- `quality_scores.json['published']` 共 **1,066** 筆,而帶 `views` 的只有 **197 筆**,
  **最小值 162** ⇒ 那是 **Top-N 截斷**,切點就在觀看數上。
  **拿它回測 = 依應變數選樣**,結論必然偏。(memory `yt-retention-is-audience-not-content` 已記過同一個坑。)
- **本機沒有任何 per-video 的「來源別分鐘」**(掃過 `STUDIO/`,沒有 traffic/source 類檔案)。
  而督導指定的應變數正是**搜尋來源的觀看分鐘**。

⇒ **要回答這題必須另外取資料**,不是把現有檔案重新切一次。

## 三、要答這題的成本(不是現在就做,是把價目表放著)

| 要取的 | 方法 | 注意 |
|---|---|---|
| per-video 搜尋來源分鐘 | Analytics `dimensions=video` + `insightTrafficSourceType` | 🔴 **200 列硬截斷**(memory `yt-autoloop-shorts-death-spiral` 記過)⇒ 209 支要分批 `filters=video==` |
| 憑證 | **`token_analytics.json`** | `token_manage.json` 缺 scope 一律 403 |
| 窗口 | 單一窗口內比較 | 🔴 **不要跨 08-27**(engagedViews 斷點);本題用 `estimatedMinutesWatched` 不受該斷點影響,但窗口仍要一致 |

⚠️ 還有一個**沒有解**的殘留混淆:個股體檢的措辭不是隨機分派的 ——
「承諾有效/情緒」那 57 支很可能是**題材本來就比較有戲**的那些(暴賺/腰斬/慘輸)。
⇒ **就算取到分鐘,觀察性回測仍只能生假設,不能定因果。**

## 四、對督導問句的直接回答

> **「值不值得做一個真的 A/B」—— 目前答不出來,而且觀察性回測答不了。**

理由:唯一不共線的切面(個股體檢內部 152 vs 57)裡,措辭仍與**題材**綁在一起,
而題材是這條線已知最強的變數之一。⇒ 觀察性回測能給的最多是「值得再看一眼」,
給不了「值不值得投入做 A/B」。

**能真的回答的做法只有一個:在個股體檢內部做隨機分派** ——
同一批股票、同一天發、只有標題措辭不同。那是產線層的實驗,不是資料分析。

⇒ 建議把這件寫成「**待 Carson 或督導決定要不要做產線層實驗**」,
而不是繼續在已發布資料上找答案。**我不會硬給一個標題建議。**
