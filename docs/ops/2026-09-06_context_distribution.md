## 三件要接手的人知道的

1. 🔴 **四支已超過 dispatch.md 的 200K 交棒線**,而 context 大小是配額的乘數
   (memory `claude-context-budget-2026-09`:同樣 500 次 tool call,800K 花 400M、120K 只花 60M)。
   反事實那行說得最清楚:**全壓 120K 的話 24h 燒量從 1,259.8M 降到 395.0M = 3.19 倍**。
2. 🔴 **近 5h 第一名是 `752726ea` = 本 session(基建線),149.0M = 67.1%**,context 峰 634K。
   ⇒ **我自己就是那個乘數**。這份文件由我寫,所以這句話要寫在最前面而不是藏在表裡。
3. **`wG:p4` 當時停在等人選三選一**:①推那四支交棒 ②查 `wF:p1` 的 288K 塞了什麼
   ③關掉三支零呼叫的閒置 session。**它自己標明那是別人的對話,不會單方面動** —— 這個判斷是對的,照留。

⚠️ 表裡的 pane 欄有幾列是 `-`,代表那個 sid 當下對不到窗格(sid 不變、窗格會變,
見 memory `herdr-pane-session-map`)。**不要拿 pane 欄當身分**,sid 才是。
