## 方法論(唯一會隨 context 消失的東西)

1. **對照觀測有四種狀態**:有且自動比對 / 有但要人算 / **有但結構上取不到** / 沒有。
   第三種最危險,因為它看起來有。
2. **修了一條路徑 ≠ 修了那個歧義** —— 要數**所有**產生那個值的路徑。
3. **「沒有對照觀測的宣稱連被發現的可能都沒有」** —— 它們不會被任何檢測抓到,只會被人撞到。
4. **改活的正式機檔一律 tmp → 讀回比對 → `os.replace`**,並先記一個可機械比對的不變量
   (memory `write-truncates-before-it-fails`)。
5. **錨點避開標點** —— 這個 repo 半形/全形混用,用標點當 pattern 會靜默命中 0 次。
