# 三個英文長尾題該不該進 main ch. 題庫 —— 2026-09-04,督導(wF:p1)

## 結論先講

**「不是加 3 支,是換掉最弱的三支」這個問法建立在一個不存在的機制上。**
而且就算換了,那三題在 main ch. **一支也產不出來**。

⚠️ 本結論**不依賴那三題的內容** —— 我到現在沒收到 sec ch. 的交接檔,
下面每一條對「任何沒有 `fact_key` 的英文題」都成立。內容拿到後不必重算,
只需確認一件事:它們有沒有 `fact_key`(見第三節)。

## 一、刪掉最弱的三題是 no-op

`produce_batch.pull_topic()` 是**嚴格排序取最優**,不是隨機也不是先進先出:

```python
cand.sort(key=_rank)     # produce_batch.py:602
...
chosen = ... cand[0]
```

未用題有 **4,471 題**。排在最後面的三題不會因為你不刪就被抽到 ——
它們本來就永遠排在 4,468 題後面。**刪除改變不了任何一次抽題結果。**

⇒ 「加 3 支」和「換掉最弱三支」不是兩個選項,後者等於前者加一個空動作。
題庫大小從來不是綁定條件,**排名位置才是**。

## 二、長片:那三題在排序**之前**就被濾掉

```python
if kind == "long":
    _grounded = [t for t in cand if str(t.get("fact_key","") or "").strip()]
    if len(_grounded) >= 5:
        cand = _grounded          # produce_batch.py:569-576
```

實測未用長片 **432 題,其中 414 題有 `fact_key`**。門檻是 ≥5,現在是 414,
所以這道**永遠是開的**。沒有 `fact_key` 的英文題連進候選池的機會都沒有。

**這不是「排得低」,是結構性不可達。** 而且它不會出現任何錯誤訊號:
題目安靜地躺在庫裡,`used` 永遠是 false,沒有人會收到「它從沒被考慮過」的通知。

## 三、短片:排在 1,850 題後面

`_rank` 回傳 `(flag, checkup, winner, news_src, depri, seo, num)`,
`winner` 是第三個鍵,壓過 `seo` 和 `num`。

| 關鍵字表 | 條數 | 非中文的有哪些 |
|---|---|---|
| `_WINNER_KW` | 19 | `0050 0056 00878 00929 006208 ETF "All in" vs` |
| `_NUM_KW` | 32 | **一條都沒有** |

一個真正的英文長尾片語(不是恰好含 `ETF`/`vs` 這種代號)命中 **0 條**,
`winner=1`、`num=1`、`seo=1`。實測未用短片 4,039 題裡:

- 命中 `_WINNER_KW`:**1,850 題(45.8%)** ← 全部排在英文題前面
- 命中 `_NUM_KW`:3,425 題(84.8%)
- 至少命中一項:**3,681 題(91.1%)**

再加上短片名額只有 `max(1, round(target*0.1))` = 每日 **1 支**,
而短片是實測不帶訂閱也不帶觀看時數的格式(memory `yt-shorts-not-converting-2026-08`)。

⇒ **main ch. 的選題函式是單語的,而且是照台股調的。** 這不是偏好問題,是 51 條
關鍵字裡 32 條純中文、19 條是台股 ETF 代號的結構事實。英文題放進來不會被選中,
不是因為它不好,是因為**這個排序函式看不見它**。

## 四、建議:那三題不要進 main ch. 題庫

三條路,我推第三條:

| 路 | 做法 | 判斷 |
|---|---|---|
| ① 硬塞題庫 | 加進去等它被抽 | ❌ 長片不可達、短片排 1,850 名後,等於扔掉 |
| ② 補 `fact_key` + 改中文框架 | 讓它排得上 | ❌ 改完它就變成一題普通中文台股題,**當初讓它有價值的東西(英文可搜、競爭低)正好是被改掉的那部分** |
| ③ **不走選題,走 `topic_override`** | `call_claude` 是 `topic = topic_override or pull_topic(kind)`(`:2417`),`--tw-lab`/`--stock` 已經是這樣繞過排序的 | ✅ 要讓三個指定題目被做出來,這是現成機制,零改動、不擾動調了幾個月的排序 |

**但在按 ③ 之前要先答一個更前面的問題:main ch. 做英文片有意義嗎?**
流量進入點是搜尋(搜尋佔觀看分鐘 47.1%),而頻道是中文台股頻道 ——
英文題被推給的仍是中文受眾。那三題的價值是**在能服務英文觀眾的頻道上**才兌現的。

⇒ 我的建議:**它們作為「需求發現」保存,不作為 main ch. 的產製項目。**
「這三個英文詞真的有人搜、搶得到」這個結論不會過期、存起來零成本;
而把它們塞進一個看不見它們的題庫,是把一個有效的發現變成三筆永遠 `used=false` 的死題。

## 附:順手抓到的三筆退化題(與本案無關,但同一次掃出來)


沒有立即危險(短片一天只有 1 支名額),但這是「排序獎勵了退化資料」的一個實例。
