## 一、先更正督導診斷的一格:**事實庫是對的**

督導檔 `2026-09-11_期間偷換_督導獨立複驗.md` §4(a) 寫:

⇒ **事實庫三組全部自洽**(451.5%/10.0年 ⇒ 18.6%;81.9% ⇒ 6.2%;701.9% ⇒ 23.2%)。

**結構上不可能不自洽**。所以這不是「憑據自己不合算術」。

真實機制是:**LLM 把 prompt 的實證資料區塊整段吐回旁白,而重述時把「非頭條數字」改掉了。**
- 三個**總報酬**(頭條數字)一字不差;六個**年化/回撤**全部被改。
- 同一句還混進 prompt 規則原文兩次(「①你唯一能當成事實講的精確數字…」)——
  這是 `llm.py:305` 已記載的失效型(12 支報廢稿裡 10 支是把 prompt 原文吐進旁白),那次沒被擋下。
- 它還自己加了「總報酬**示意**」「年化**約**」——而「示意」正是 `fact_source_guard.HEADGE`/`fact_guard._HEDGE`
  的誠實揭露白名單詞 ⇒ **加上「示意」這個動作本身就把守門關掉了**。

⇒ 病名要改。不是「憑據不合算術」,是「**有憑據的句子裡,非頭條數字在被重述時被改掉,而遮詞把守門關掉**」。
   算術自洽只抓得到這個病的一部分(見 §3 ③)。

## 二、為什麼這道判準值得存在:它和誠信守門**正交**

`fact_source_guard.unsourced_claims()` 問的是「這個數字在事實池裡找不找得到」,
而池是一個**扁平的 float 集合**(memory `yt-fact-guard-pool-saturation`:全域 38,231 個數字)。
6.5 這種數字幾乎一定在池裡 ⇒ 整句放行。**池子越大,守門越弱。**

算術自洽不問數字存不存在,問三個數彼此合不合。**池子被餵飽打不倒它。**
這是納入的最強理由:它是目前唯一一道不隨事實庫成長而衰減的判準。

⚠️ 落地時必須明寫:**本判準不認 HEDGE**。遮詞(示意/假設/約)可以豁免「沒有憑據」,
不能豁免「算術上不可能」。實例:詮欣 6205 原句是「總報酬**假設為** 215.7%(年化 6%)」。

## 三、三個母體(memory `gate-verification-population`)

判準:同句抽出 (R, a, n_stated) ⇒ `n_implied = ln(1+R)/ln(1+a)`,要求 `|n_implied - n_stated| <= 1.5 年`。
不比較 a 本身,因為期間常寫成「近10年」而實際 10.18 年 ⇒ a 沒有固定尺度,n 有(年)。

## 五、建議的落地方式,以及**為什麼不要 fail-closed**

**分兩段,第一段是我的,第二段不是。**

**第一段(基建線,我做):落成每日守望,report-only,不擋產線。**
理由:偵測成本≈0(一次全掃 818 支 < 3 秒)、正交於數字池、失效方向可控
(抽不到三元組一律算「不可判定」不算通過)。形狀和 09-10 那三支哨一致,一併吃互查
(`scripts/watch_crosscheck.py`)⇒ 它沉默的時候會有人叫。

**🔴 為什麼不建議做成 fail-closed 閘門:**
命中率 5.3%,看起來很便宜 —— 但 memory `yt-period-swap-integrity` 是我自己的事故:
**「重生不是重試,是重擲同一顆骰子」**,加閘門的成本要用接近 r 估、不是 r^n,
我上次照 r³ 估(以為 1.2%)結果讓產線停兩天,實測是預期的 11~274 倍。
5.3% 的單稿違規率配上非獨立重生 ⇒ fail-closed 的真實停產成本無法從 5.3% 推出來。
而且擋了也治不到根:數字在事實庫裡本來就是對的,錯在**重述**。

**第二段(產線,主頻道線的地盤,我不做):真正的修法是不要讓 LLM 重述年化。**
13 支裡 6 支是 A 型(重述時改數字)。結構修法和 08-22/08-28 那兩次同型
(把期間黏進數字本身,見 `tw_facts_engine.calc_three_way_showdown()` 的兩段註解):
**把年化/回撤從「可自由重述的文字」改成「不可重述的引用」**。
⚠️ 這一格我只提出,不動手。

🔗 **交叉指標(同一種病的另一個病灶)**:`produce_batch.py:1275` 的**規則ⓜ**(0050 對照必須在同一句標明期間)
**只寫在 prompt 層**,而 09-06 的片逐字違反它 —— memory `verification-that-cannot-fail` 的**第零種失效**:
規則活在一個「被違反時不產生任何輸出」的層。本文 §1 的「示意」把守門關掉、§3 的定義域只有三成,是同一種形狀:
**規則在勸,不在擋。** 另見 `docs/ops/2026-09-10_watch_silence_rootcause.md` §6。
