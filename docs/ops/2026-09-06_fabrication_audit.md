| 判定 | 定義 |
|---|---|
| **確認捏造** | 旁白給出**具體數字**,而該 code 在 `stock_checkup_facts.json` 裡**沒有**對應的 fact,<br>或**有但數值/期間對不上** |
| **疑似** | 旁白提到該類別但**沒給數字**,或給的數字**無法明確對應**到有或沒有 |
| **誤判** | 那個數字來自該檔的**其他合法來源**(價格序列、回測結果、別條 fact),<br>或它是**比喻 / 假設 / 前瞻條件句**而非事實陳述 |

## ⚠️ 「56% 捏造率」的分母

**那個分母是「事實 5~8 條的已發布片(45 支)」,不是全頻道。**
9+ 條事實的是 **2%(1/57)**。收緊判準後,全體已發布 175 支的命中是 **15 支 = 8.6%**。

🔴 **「56%」一旦脫離分母被引用,會變成「全頻道 56% 造假」,而那不是真的。**
引用這個數字時必須連分母一起講。

## 偵測器
`scratchpad/fab_scan.py`。判準:旁白給了某類事實的具體數字,而該檔**沒有**那條 fact,
且該數字**不等於該檔自己任一條 fact 裡的數字**。

🔴 **白名單是「每檔約 50 個數字」,不是全域 38,231 池** ——

per-stock 白名單不適用那個反對意見。

(假設/如果你/舉例/想像/例如/假如/試想/打個比方)。

> 「假設你在 2007 年買進,**當時本益比衝到 23 倍**」——
> **假設的是「你買進」這個動作,而「當時是 23 倍」是關於世界的斷言。**

> 決定性的一問:**觀眾看完會不會以為 2007 年那檔的本益比真的是 23 倍?** 會。
> 而本益比不在 fact 裡、也不是我們算得出來的(要 EPS + 當時股價,
> 而那幾檔連 EPS fact 都沒有)⇒ 那個數字只能是 LLM 給的。
