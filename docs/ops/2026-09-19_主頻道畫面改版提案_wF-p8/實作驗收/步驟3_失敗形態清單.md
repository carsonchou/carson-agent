# 步驟 3(方案 B)失敗形態清單 —— 寫在閘門設計之前

紀律依據:`docs/ops/dispatch.md` §6「失敗形態先於閘門」。本檔先列「這個功能會怎麼壞」,
閘門與陽性對照都必須逐條對應得上;**閘門設計不得回頭刪改本清單的任何一條**
(`fallback-criterion-must-predate-the-result`)。寫作時間點:2026-09-19,
在 `scripts/narration_number_gate.py` 存在之前。

功能是什麼:把「旁白**當下這一句**正在唸的數字」大字印在畫面上。
旁白是中文數字(「負的百分之六十九點八」),所以這個功能天生就是一條
「把不確定的轉換結果印成事實」的路徑 —— 沒有閘門就是誠信紅線
(memory `yt-integrity-fabricated-stats-fix`)。

## 硬性失敗形態(派工單指定,一條都不准漏)

### ① 旁白數字與畫面數字取自不同視窗
旁白引用事實庫全歷史值(3714 最大回撤 **-69.8%**),但畫面上那張圖是
`render_ffmpeg.py` 的漸進揭露圖,只畫到資料的前 r 比例,圖說當場重算成 **-59.9%**。
兩個數字同時在畫面上 = 畫面在打臉旁白。
註:`concept_visuals.py:919-924` 的鐵律「圖表的資料窗口必須跟旁白引用的窗口一致」
已經因為同一個病灶廢掉 variant 尾窗,但 **reveal 有一模一樣的缺陷且從未修**。
→ 閘門必須同時比對**事實庫**與**該幀圖說自己的數字**,只中一邊不算過。

### ② 旁白數字在事實庫根本沒有對應欄位
實例(同一支 3714 的旁白):「假設你投入**一百萬**…資產可能會縮水將近**七十萬**」、
「最終會變成**三百八十八萬六千元**」、訂閱 CTA 的「全台股 **1925** 檔…目前完成 **223** 檔」。
這些是舉例/進度,不是體檢事實欄位。印出來等於宣稱「這是我們算出來的事實」。
→ 查不到完全吻合的欄位 → 不印,退回 CTA / 字卡版面。

### ③ 同一段裡有兩個以上數字
實例:「總報酬會是負的百分之二十八點一,年化報酬率為負的百分之五點七」
(同一句兩個數字,分別對到 `total_return` 與 `cagr`)。
挑錯就會出現「嘴巴講年化、畫面印總報酬」。
→ 必須確定印出來的是**這一個字幕 cue 當下正在唸**的那個;同一 cue 解析出
兩個以上都通過驗證的相異數字 → 無法確定是哪一個 → 一律不印(fail-closed)。

## 我在讀旁白與正式碼時額外找到的失敗形態

### ④ 中文數字轉換本身出錯而無人察覺
「百分之兩百八十八點六」「一千六百四十天」「三點二一元」三種構詞都不同。
轉錯一位數,後面每一關都只會拿錯的值去比,比不中就靜默不印 —— **看起來像閘門有在守,
其實是轉換器壞了**(memory `detector-failure-shapes-2026-09`:偵測器自己壞掉)。
→ 轉換器要有自己的斷言,且陽性對照要餵「轉換正確但事實庫沒有」與
「轉換錯誤」兩種輸入,確認兩者都被擋。

### ⑤ 表示法映射被當成「模糊比對」的後門
事實庫存 `-0.6981959387610676`,旁白唸 `-69.8`。要比中就得做
ratio→百分比、元→元、億元→/1e8 的換算。這個換算一旦寫成「差距小於 x% 就算中」,
閘門就從精確比對退化成模糊比對,①③ 會整批漏掉。
→ 換算表必須是**逐欄位列舉的固定表示法**,比對時 `round(顯示值, 旁白的小數位) == 旁白值`,
不准有容差參數。

### ⑥ 退場版面自己是假的
fail-closed 退回的 CTA 版面若印「已完成 223 檔」而那個 223 是寫死的,
就是用一個編造數字取代另一個編造數字。
→ CTA 版面的每個數字也要有事實來源,拿不到就只出純文字字卡。

### ⑦ 閘門擋掉太多,等於功能沒上線
若絕大多數 cue 都被擋,畫面上永遠看不到數字,而驗收又只看「有沒有印錯」,
就會得到一個「不可能失敗的檢查」(memory `verification-that-cannot-fail`)。
→ 驗收必須同時報**通過率**(母體=全片有數字的 cue),並且要有至少一張
「閘門放行、數字印在畫面上」與一張「閘門擋下、改出 CTA 版面」的實幀。

## 閘門的判定順序(依上列形態推導,不是反推)

1. 取這一刻的字幕 cue 文字(= 旁白當下正在唸的那句)。
2. 中文數字 → 數值 + 單位,解析不出來 → 不印(④)。
3. 逐候選查事實庫:以固定表示法表算顯示值,`round(顯示值, 旁白小數位) == 旁白值`
   才算中;沒中 → 不印(②⑤)。
4. 通過驗證的相異候選 ≥2 → 不印(③)。
5. 唯一候選再和**這一幀圖說自己的數字**比:同一指標而數值不同 → 不印(①)。
6. 全過 → 印;任一關沒過 → 不印該數字,退 CTA / 字卡版面(⑥)。
