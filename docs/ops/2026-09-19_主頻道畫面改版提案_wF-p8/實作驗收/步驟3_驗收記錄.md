## 舊版錯在哪 —— 不是實作 bug,是素材選錯

舊版 `_build_num_pops` 拿「該段圖表 sidecar 的 `key_numbers[0]`」,印在**段落起點**。
**段落起點那一刻旁白在唸什麼,全檔沒有任何一行查過。** 圖上印 -69.8% 而嘴巴正在講
-28.1% 是完全可能的,而且沒有任何東西會擋。

舊版註解寫「上線前已過:樣張四方一致(pop=圖=圖說=旁白)」—— 那是上線當下抽樣看過,
**不是程式保證的性質**(memory `verification-claims-in-commit-messages`)。
抽樣看過的東西會隨著題庫改變而失效,程式保證的不會。

## 閘門判定順序(由失敗形態推導,不是反推)

| 關卡 | 擋掉的形態 |
|------|-----------|
| 1. 解析這一刻字幕 cue 的中文數字 → (值, 單位, 旁白唸到的小數位) | ④ 解析不出 → 不印 |
| 2. 逐欄位固定表示法換算,`_round(顯示值, 旁白小數位) == 旁白值` **且旁白點到該欄位的指標詞** | ②⑤ 沒中 → 不印 |
| 3. 通過驗證的相異候選 ≥ 2 | ③ 不確定在唸哪個 → 不印 |
| 4. 唯一候選 vs **這一幀圖說自己的數字**,同單位不同值 | ① 視窗不一致 → 不印 |
| 全過 → 印;任一關沒過 → 退純文字 CTA(⑥:一個數字都不帶) | |

沒有代號 / 事實庫沒這檔 / 閘門模組載不進來 → **一個數字都不印**。
「驗不了就不印」比「印了再說」保守且可解釋(memory `fail-closed-criterion-is-explainability`)。

### 兩個非顯而易見的設計點

**不能用內建 `round`。** 它是銀行家捨入:`round(4.5) = 4`。旁白「四年半」被解析器讀成
4 年時,會跟事實庫的 `max_underwater_years = 4.5` **比中**,閘門反而替一個解析錯誤背書。
改用半數一律進位的 `_round`,邊界上寧可比不中。

**比對必須包含「旁白有沒有點到這個欄位的名字」。** 只比「數值 + 單位」會比中**語意無關**
的欄位 —— 實測本片:「這意味著如果你在這**一年**持有富採」比中了 `consecutive_years=1`、
「即使你抱了**五年多**」比中了 `max_underwater_years=4.5`(四捨五入後都是 5)。
兩句都不是在講那個欄位,印出去就是拿一個真實欄位替一句無關的話背書。
所以 `_REPR` 每個欄位都帶第三欄「旁白必須出現的指標詞」,點不到名 → 不印。

## 陽性對照 —— 每個形態都要證明閘門**會**擋

`poscontrol_step3.py`,跑在推上正式碼之後的那份閘門上。

| 餵進去的輸入 | 期望 | 實際 |
|--------------|------|------|
| ① 旁白 -69.8%,圖說 -59.9%(同指標不同視窗) | 擋 | `① 圖說是 -59.9%,旁白是 -69.8%,視窗不一致` |
| ② 「全台股 1925 檔…目前完成 223 檔」(進度數字) | 擋 | `② 事實庫沒有完全吻合的欄位` |
| ② 「假設你投入一百萬」(舉例本金,單位「萬元」不在表內) | 擋 | `④ 這句沒有解析得出的數字` |
| ③ 「總報酬負二十八點一,年化負五點七」(同句兩個都對得上) | 擋 | `③ 同一句有 2 個通過驗證的數字,無法確定在唸哪個` |
| ④ 「四年半」(解析只讀到 4,半數進位使其比不中 4.5) | 擋 | 擋下 |
| 假陽性回歸:「在這**一年**持有富採」 | 擋 | `② 事實庫沒有完全吻合的欄位` |
| 假陽性回歸:「即使你抱了**五年多**」 | 擋 | `② 事實庫沒有完全吻合的欄位` |

最後兩列是形態④ 要求的「轉換正確但事實庫沒有」與「轉換錯誤」兩種輸入,兩者都被擋。
陰性對照存在的意義是形態⑦:如果全部都擋,這支檢查就是「不可能失敗的檢查」。

## 已知天花板(照實記,不藏)

**形態① 的比對是「同單位、數值不同就擋」,不分辨兩個數字是不是同一個指標。**
上面那個例子裡,-28.1%(含息總報酬)與 -51%(價格變化)其實是兩個不同指標,
嚴格說不算互相矛盾,是被**過度攔截**了。

保留這個過度攔截,理由是:要分辨指標得再做一次「圖說數字 → 欄位」的推斷,
而那個推斷錯的時候會**往放行的方向錯**(把該擋的放過去)。
在誠信紅線上,寧可少印幾個數字,不要多印一個錯的。
真要放寬,正確作法是讓 `concept_visuals` 在 sidecar 裡直接寫出圖說每個數字的欄位名,
而不是回頭去猜 —— 那屬於方案 A 的範圍,不在這一步。

**overlay 位置沿用舊版(畫面正中央),會蓋在圖表上。** 這不是這次改的,
素材換了、位置沒動,所以不列為本步驟的回歸;要挪位置屬於版面重排(方案 A)。
