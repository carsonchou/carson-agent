**根因 = 入口是觸發詞白名單。** 進入邏輯前要先過:

```python
if not _re.search(r"同期|同時期|同一?段?(?:期間|時間|時期)|相同(?:期間|時間|時期)"
                  r"|同樣的(?:時間|期間)|這段(?:期間|時間)", s): continue

```

安勤逐句:提到 0050 的四句(34/57/58/59)**觸發詞全部沒中**。句 34 是
「如果將**同樣的資金和時間**,投入到…0050」——`同樣的(?:時間|期間)` 因為中間插了「資金和」而不匹配。
這正是 memory `gate-blind-while-target-evolves`:**判準是樣式清單,而被監控物會被改寫,追不上時它不報錯。**

🔴 **自我封閉迴圈**:`fix_period_disclaimer._refresh_candidates()` 用**同一個** `_long_mixed_period`
重建那 84 支名單 ⇒ 閘門看不見的片,永遠不會進名單。
盲區在「已修」宣稱和「受影響清單」**兩邊同時隱形**。

| **A 不動** | 保留原句 | 那句話在字面粒度上對 49.3% 的後續影片是假的,且已印在 84 支描述欄。這是 memory `yt-integrity-fabricated-stats-fix` 那條的**第二個實例**(07-13 建守門而「已修」是假的);若被觀眾對照抓到,傷的是頻道唯一的定位 |
