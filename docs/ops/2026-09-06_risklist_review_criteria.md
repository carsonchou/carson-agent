## 判準(沿用 2026-09-06 稽核檔,加上今晚收緊的三條)

| 判定 | 定義 |
|---|---|
| **確認捏造** | 旁白給出**具體數字**,而該 code **沒有**對應那一類的 fact |
| **疑似** | 提到該類別但沒給具體數字,或數字無法明確對應 |
| **不算** | 數字來自該檔**其他合法來源**(價格序列/回測/別條 fact),或**四捨五入引用自身事實**,或它是比喻/純假設舉例 |

### 今晚收緊的三條(新判準,督導 04:0x 批准)

1. **假設句裡的世界斷言不豁免。** 「假設你在2007年買進,**當時**本益比衝到23倍」——
   假設的對象是「你買進」這個動作,「當時是23倍」是關於世界的斷言。
   決定性一問:**觀眾看完會不會以為那是真的?**
2. **回指詞(當時/當年/當初/那時/該年)往後傳**到同句後續子句;
   **指名年份不往後傳**(年份可能在括號舉例裡)。
3. **量綱必須一致**:白名單不分單位,所以「元」不可以替「%」背書;
   容差純相對(0.5%),**不留絕對地板**。

### 四種已知偽陽性(逐支排除)

明說沒有資料(正確行為)/ 比喻 / 前瞻條件句(無指名時點)/ 中文數字轉換失敗。
再加今晚新發現的兩種:**四捨五入引用自身事實**(2326.3% → 「二千三百二十六」)、
**數字與類別關鍵字隔太遠**(片尾 CTA 的「股息」把前面的「11年」拖成股利宣稱)。

## 🔴 預期值(**在讀第一支之前寫下**)

督導的紀律:**如果 59 支全中,要懷疑的是判準太寬,不是災情擴大。**

我的預期,以及理由:

| 項目 | 預期 | 理由 |
|---|---|---|
| 59 支裡**已處置**的 | 15~21 支 | 21 支已下架的多半就是從這個風險條件裡挑出來的 |
| **新增確認捏造** | **0~3 支** | 閘門已掃過全部 184 支已發布適用片、擋下 23 支(=21 已處置 + 2357 + 6446),所以閘門觀點下**新命中的空間接近 0**;唯一的新增來源是**放寬豁免的重掃**,而上一輪對全部 184 支做同樣的事只多出 5 支候選、其中只有 1 支(2891)成立 |
| 判準太寬的警訊 | **> 10 支** | 超過就停下來重新檢查判準,不要繼續下架 |
| 判準太窄的警訊 | 0 支且**放寬豁免也 0 支** | 那要懷疑掃描沒真的跑到(對照上一輪「豁免全關命中 0 支」那個假答案) |

⚠️ **沒有預期值的觀測不是驗證。** 上面這張表寫在讀之前,就是為了讓
「新增 0 支」和「掃描壞掉」這兩件事能被分開 —— 它們的輸出長得一樣。

## 方法

1. 59 筆逐筆對到 slug 與 code,標出哪些**已處置**(21 支已 private)。
2. 對未處置的跑**現行判準**(閘門 `scan()`)。
3. 再跑一次**豁免全關**(最大涵蓋),取差集 = 被豁免規則壓住的,**逐支人工判讀**。
   ⚠️ 上一輪跑這個時我的儀器是壞的:關掉豁免會讓陰性 fixture 命中 ⇒ 自檢失敗
   ⇒ 每支都回 blocked 但 `code=None` ⇒ 全被過濾條件丟掉,印出假的「0 支」。
   **這次直接呼叫 `scan()`,不要走 `check()`。**
4. 有新命中 → 照規格處置(設 private 不刪除、逐支記錄、**執行後**再 commit、
   獨立儀器 + 陰性對照確認當前狀態並記時間戳)。
5. **中途落檔**,不等 59 支全讀完。
