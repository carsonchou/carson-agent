## 三、🔴 完播率會被片長單獨推動 —— 這一條單獨足以否決它

memory `yt-retention-is-audience-not-content` 早就寫著「完播率 vs 片長 r=−0.643 是
**1/片長的影子**,比較不同長度一律用絕對秒數」。**本檔在個股體檢子集上獨立重現了它:**

| | 相關係數(n=62,有片長且有指標) |
|---|---|
| 片長 vs **完播率** | **−0.531** |
| 片長 vs **平均觀看秒數** | +0.177 |

**而且這不是理論風險,現有稿子上就看得到它在騙人。** 拿「稿子裡有沒有提到某個基本面詞」
分兩組(這正是這次改動要做的事的自然實驗版):

**恆等於** `round(avg_dur ÷ 片長 × 100, 1)`(62 支最大偏差 0.246pp)——
**它不是一個獨立的量測,它就是前兩欄相除。**
控制片長之後,那個 +3.16pp(t=2.17)掉到 **+0.50pp(t=0.35)**。
⇒ **完播率沒有攜帶任何 avg_dur 和片長以外的資訊。** 這比本節原本的主張更強。

⇒ 如果驗收指標是完播率,而改動讓片子長度動了,我們會拿到一個 **t>2 的顯著結果**、寫進 commit,

## 六、留言:不要當率,要當捕捉器

n 太小當**比率**用是無效的,而且產線自己發的留言混在裡面
