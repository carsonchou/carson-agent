## 否決 ②(撬開 SUGGESTED / BROWSE)

你要的是證據不是希望,證據是反的:

- `BROWSE_FEATURES` = 0,**在 58,063 觀看的量級上仍然 = 0**。權重不是變數,因為權重已經給過了。
- `RELATED_VIDEO` 不是 0,但它是 **3.0% 觀看**。就算副頻道把它從 0 撬到主頻道的水準,
  對應的是 375 × 3.0% ≈ **11 次觀看**。「量級會跳一個數量級」在這個基數上是 11 次。
- 而副頻道現存 23 支非直式影片合計 **16 次觀看** —— 推薦系統要有觀看歷史當種子,
  0 觀看就沒有種子。這是自舉問題,不是調參問題。

⇒ **②沒有可撬的門。** 不是難撬,是這個經營者從來沒有證明過那扇門存在。

## 否決 ①(當主頻道的試驗場)

①是三個裡最誘人的,因為它每一句都對:副頻道的 Cloud 專案閒置、發布不花主頻道配額、
壞掉不心疼,而主頻道每個發布名額值 4~7 觀看小時(memory `yt-marginal-value-per-video`)。
**成本確實接近 0。** 但成本 0 不等於價值 > 0:

1. **量測地板太高。** 副頻道每支 9.3 次觀看。今天那個對照能成立**只因為效應是 13 倍**。
   任何小於一個數量級的效應在這裡量不出來,而主頻道有 58,063 觀看,能量到 5% 的差異。
   ⇒ 副頻道只能回答「答案是不是一個數量級」的問題。
2. **那類問題已經被問完了。** 16:9 短片進不進 Shorts feed = 今天答完;
   冷啟動頻道排得進搜尋第一頁能不能帶流量 = `hungry_judges` 排第 8、**0 觀看**,答完;
   Shorts 換不換得到訂閱與時數 = 主頻道自己的資料早就答完
   (memory `yt-shorts-not-converting-2026-08`)。**我列不出第四個。**
3. **只有平台機制會轉移,內容結論不會。** 副頻道是英文心理學,主頻道是繁中台股。
   受眾、語言、搜尋入口都不重疊。
4. 🔴 **「試驗場」這個標籤本身是這條線最危險的東西。**
   memory `distribution-before-quality` 的教訓是:沒有分發的線可以無限期地「一直在進步」
   而不出現任何錯誤訊號。**「它是試驗場」正好是那種讓歸零的線繼續下去、
   而且聽起來很有紀律的理由。** 這條線已經示範過一次了(10 小時 / $194)。

⇒ 選①要交的是「哪些變數只能在這裡測」,**而我列不出一張非空的清單**。列不出來就不能選。

## ③ 是什麼、不是什麼

- **不是**刪頻道。YouTube 頻道留著不花錢,62 支影片留著當歷史證據。
- **是**結束這條**線**:不排實驗、不產內容、不派 agent、不留督導、不佔渲染時段與記憶體。
- 發布排程已於 09-02 停用並行為驗證過(`44a9de2a`,crontab 732/733/734 註解,
  復原只要取消註解、約 60 秒生效、備份在 `crontab.txt.bak-20260902`)。
- 交接檔已在 `docs/ch3-handoff-2026-09-03.md`。

**不選「都做一點」的意思是:沒有實驗排程、沒有休眠待命清單。**
未來真的出現一個「只能在這裡測、而且預期效應一個數量級」的問題時,
再照交接檔重啟——那時它是一個有具體問句的新決定,不是一條掛著名義的舊線。
