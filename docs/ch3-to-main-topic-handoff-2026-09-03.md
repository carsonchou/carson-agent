## 2. hungry_judges 是最有價值的一筆資料,因為它兩條都過了然後還是 0

`hungry judge effect` 第一頁實測(`search.list`,09-03):

| 名次 | 觀看 | 頻道(訂閱) |
|---|---|---|
| 1 | 806,627 | StarTalk(5,880,000) |
| 2 | 37 | facts4you(0) |
| 3 | 235 | Psych Papers(879) |
| 5 | 23,532 | Wisdom Time(3,090) |
| **8** | **0** | **我們自己的片(1 訂閱)** |
| 10 | 65 | John C. Checco(4) |

我們**已經在第一頁了**,標題含完整 query 字串,而且第一頁沒有大頻道壟斷。
**然後 0 次觀看。**

→ 所以真正的結論不是「搶不到位」,是 **搶得到一個沒有人走的門,和搶不到,結果一樣**。
判準少了第三條:**這個 query 到底有沒有流量**。第 1 名那 80 萬來自 StarTalk 的
588 萬訂閱,不是來自這個 query;同頁小頻道全是兩三位數,那才是這個 query 的真實量級。

## 3. 就算數字不是 0,這三個題目也不該進 main ch. 的題庫

main ch. 是**繁體中文的台股頻道**(題庫 key 長這樣:`S_72法則`、`S_DCA核心`、`S_夏普值`),
搜尋進站 47.1% 靠的是「個股體檢【股票名】」這類中文查詢型標題。
**英文心理學複製危機題目與它的受眾、語言、搜尋入口完全不重疊**,
放進去不是排序問題,是類別錯誤。交辦時提到的「跟現有題目比、換掉最弱的三支」
這個框架本身是對的(配額是綁定條件、產能不是),但它預設兩批題目在同一個排序空間裡,
而這兩批不在。

## 4. 真正可轉移的東西:量測方法(三個坑)

這才是這份交接的實際價值,任何線選題時都會踩:

1. **suggest 端點會把你打的完整字串原樣回吐。** 打 `hungry judge effect` 會拿到它自己。
   → **要打前綴看它補不補得出來。** 這一個坑就讓 09-02 那次量測多算了至少一支。
2. **「第一頁最高觀看 ≥ N」量的是頻道觸及,不是 query 的量。**
   → 要看**同頁小頻道**的觀看數。全是三位數就代表這個 query 幾乎沒有流量。
3. **排得進第一頁 ≠ 拿得到流量。** 見第 2 節。

工具:`ch3_lab/independent_demand_probe.py`(已在 `4b096e94` 標註它自己的兩個坑,
並附 `prefix_probe()`)。memory:`search-demand-measurement-traps`。
