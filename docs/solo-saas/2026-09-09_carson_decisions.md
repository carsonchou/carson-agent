## 送上去的那一題:這條線現在要不要開「最小的一格」?

### 它在問什麼

起始授權是三句話:**不辦新金鑰、不部署對外、不花任何一塊錢。**
在這個範圍裡,「有沒有人要這個 App」這個問題**只有一種答案:讀別人的帳本**。

### 為什麼需要他拍板,而不是我自己判

因為候選清單做完之後,浮出一件推翻派工前提的事:

> 🔴 蒐到的三個「先驗證再開發」實例(Buffer / IndieHackers / DEV.to),**沒有一個是零成本零上線的**,全部都要對外發布。
> 也就是說:**「不上線、不花錢,我怎麼知道有沒有人要」這一題,在證據裡一個實例都沒有。**

而讀別人的帳本回答的是「市場裡有錢」,不是「我拿得到人」——
memory `search-demand-measurement-traps` 量過那個落差:**同題、同標題、同一頁,差 177 倍。**
這正是 ch3 付過學費的形狀(10 小時 / $194 品質修正,22 支長片合計 11 次觀看;`distribution-before-quality`)。

⇒ 所以這不是「要不要早點上線」的效率問題,是**「這條線接下來幾週是在做產品,還是在重演 ch3」**的問題。
我不自行認定 —— 這件事會產生外面看得到的結果,判準說停下來問。

### 他答 A 或 B 各會發生什麼

| **A** | **維持現狀**,一格都不開 | 做候選 1 的本機規則版(財經內容數字溯源 + 誠信守門)。它的使用者是 **YT 線自己**,不是外部市場 —— 那是一個真實、反覆發作、有帳可查的痛(`yt-integrity-fabricated-stats-fix`:07-13 建了守門而「已修」是假的,09-06 又復發) | 誠實講:選 A 之後,**這條線暫時不是 SaaS 線,是內部工具線**。我不會再宣稱它在驗證市場需求 —— 它沒有 |
| **B** | **開最小一格**:允許開**一個** host 帳號,掛**一個** landing page。不接金流、不投廣告、不開社群帳號 | 用候選 1 或 2/3 做一頁,量的唯一指標是「有沒有陌生人留 email」。這是本線第一個**自己的**需求訊號 | ⚠️ 這一格同時跨兩條:**對外露出**(一個公開網址)+ **新帳號**(免費方案也算,判準是有沒有新開帳號)。B 不是「小一點的 A」,是真的跨過去 |

### 我的建議(是建議,不替他決定)

**選 A,但要知道自己選了什麼。**
理由:候選 1 是七個候選裡**唯一**核心不需要打付費 API 的,也是**唯一**手上已經有真實使用者的
(即使那個使用者是我們自己)。先把它做出來,這條線至少產出一個會被用的東西,而不是一個沒人看的 landing page。
⚠️ 但選 A 就要接受一句話:**這條線在 A 之下不會產生任何市場需求證據。** 那個問題只是被延後,不是被回答。

## 不送上去的四題(我用預設值往前做,答案來了再改)

留在這裡是為了**留痕**:如果之後方向不對,要查得到我當時假設了什麼。

### 1. 本機開發階段的 LLM 呼叫,算不算「花錢」?
- **預設值:算。** ⇒ 我不打。用 repo 現有的 OpenRouter 預付餘額不算辦新金鑰,但餘額會少 = 帳單上看得到。
- **代價:七個候選裡有六個的核心就是打一支付費 API,所以這個預設值等於把候選 2~7 全部凍住,只剩候選 1 可做。**
- 為什麼不送:這個預設值**是安全的那一邊**,而且它不會讓線停下來(候選 1 照做)。他哪天說「本機開發不算」,解凍即可。
- 🔴 附註:我第一版把候選 2、3 判成「不用碰紅線」,被獨立驗證抓到 —— 我對候選 4(TTS)套了「本機免費版不足以判斷產品行不行」,卻沒對同構的 2、3 套同一條。所以這裡我不再自行認定它不算。

### 2. 候選 1(有分發沒外部驗證)還是候選 2/3(有外部驗證沒分發)?
- **預設值:候選 1。** 在第 1 題的預設值之下,2/3 根本做不出可用版,這個取捨自動塌成一個選項。
- 只有第 1 題或授權邊界鬆動時,這題才重新變成一個真的取捨。

### 3. 批量短影音導流
- **預設值:走到那一步之前先回報,不順手做。** 照總督導 2026-09-09 指示。
- 現在離那一步很遠(還沒有東西可導流),不佔他的額度。

### 4. GymLog 要不要補一個計數器?
- **預設值:不補。**
- 代價:它會繼續沒有任何使用訊號。但**這條線不依賴它** —— 已經查明它不是分發樣本,是 `distribution-before-quality` 的又一個實例(站台活著、零計數器、Auth 沒啟用、Firestore 規則正確擋讀、repo 流量量的是 repo 頁不是 App、README 的安裝路徑根本沒用到 GitHub Pages)。

## 追記 2026-09-09:品安 8088 那支片的查證結果 —— 我上一輪回報錯了

總督導要我確認「那支把 739.8 萬寫成 6,398 萬、還長進標題的片還在不在線上」。
查完的結論是:**在線上,但那個數字不在那支片上。我把兩份不同的稿子講成同一份了。**

### 事實

同一檔股票有**兩份**稿子,檔名都帶 `8088` 和 `6398`,但 `6398` 指的不是同一個東西:

| | 隔離的那份 | 上線的那份 |
|---|---|---|
| 檔名 | `…抱品安18年賺6398很爽回測揭` | `…抱股18年賺6398小心-776` |
| 位置 | `output/_bad_leak/`(prompt 洩漏隔離區) | `output/` 根目錄 |
| `6398` 是什麼 | **六千三百九十八萬元**(金額,錯的) | **639.8%**(總報酬率,對的) |
| numerus 判決 | CONTRADICTED(100萬×7.398=739.8萬) | CONTRADICTED **0** 個 |
| 在 `uploaded_ledger.json` | **不在** | 在 → `_SeLof6bHAc` |

⇒ **放大 8.6 倍的那個數字從來沒有上線。** 它在被 prompt 洩漏閘門攔下來的那份稿子裡,
而那份稿子沒有對應的影片。上線的是同題重做的另一份,標題寫的 639.8% 是它自己算對的總報酬率。

### 上線那支的現況(2026-09-09 唯讀查證)

- `_SeLof6bHAc` — **public**,690 次觀看,發布於 2026-08-28。
- 儀器有陰性對照:同一次查 50 支,回 42 public / 8 private ⇒ `privacyStatus` 這個欄位會變,
  「public」是真的讀數,不是恆定輸出。(照 `yt-readback-stale-cache`:同一個儀器問三次不算驗證。)
- 🔴 **我沒有改它、沒有下架、沒有動它任何狀態。** 全程只有 `videos().list`。

### 那支片上真正的缺陷(比原本說的小,但不是沒有)

numerus 沒有判它 CONTRADICTED,但判了一條 BARE,而那條 BARE 指到一個真的問題:

> 「ALL IN 0050 **十年**賺**一千八百萬元**,只是一個很漂亮的數字」

這是一支**品安 8088、十八年**的片,結尾談的卻是 **0050、十年、1,800 萬** —— 串稿殘留。
同一支片前段還有:「假設你以**一萬八千點**的價格入手…你的投資可能整整**虧掉一萬八千點**」,
拿指數點位描述個股,而且「整整虧掉」與同句自己給的 −77.6% 不符。

### 給 Carson 的判斷題(需要他拍板的部分)

一支公開、690 次觀看的片,結尾把主題講成另一檔股票另一個年期的另一個金額。
**要不要動它是對外動作,我不碰。** 選項只有兩個:留著,或由 YT 線去修描述/重上。

⚠️ **急迫性更正:我上一輪說「這件事比那五個問題急」,那是建立在「8.6 倍長進標題」上的,而那個前提是錯的。**
現在它是一支有串稿瑕疵的片,不是一支帶著放大 8.6 倍數字的片。**不該再排在授權邊界那題前面。**
