# 旗艦格式提案:《抱得住嗎》

> 一個賭注,不是一張選單。2026-09-06。

## 先推翻一個候選頭條

督導提的「**我把全台股 1,925 檔跑過一遍,只有 34.9% 賺錢**」——**這句不能講。**

memory `taiwan-universe-backtest` 的原文是:**1,841 檔、Triple SuperTrend 策略、
long-only、用加密貨幣調出來的參數**,結果「只有 643 檔(34.9%)獲利」。
那句話量的是**一個策略**的勝率,不是**股票本身**會不會賺。

⇒ 講成「只有 34.9% 的股票賺錢」是**把一個數字搬離它的適用範圍**——
和今晚正在處理的捏造是同一族,只是規模大得多:**旗艦片的假頭條,比一支 2 次觀看的片裡的假數字嚴重一個量級。**

## 真正只有我們說得出口的那句

我剛從已算完的 **582 檔**完整長期回測算出來(不是估的,不是舊記憶,是現在跑的):

| | 中位數 | 分佈 |
|---|---|---|
| 含息總報酬 | **+572%** | 賠錢的只有 5.7% |
| **最大回撤** | **−73.8%** | **95.2% 的股票曾經腰斬以上** |
| **最長套牢期** | **7.1 年** | 71.7% 套牢過 ≥5 年;**30.9% 套牢過 ≥10 年** |
| **同期贏過 0050** | — | **只有 30.7%(178/580)** |

**這四行就是旗艦片。** 而它們回答的是**觀眾自己提出的那個問題**:

> 「有八成的持有人,就僅僅持有一兩張。所以那種持有 0050 達到 1200% 超高報酬的人,
> **永遠只出現在網路、永遠在回測資料**。」 ——@user,2026-08-19

他說對了。而**我們是唯一有資料能證明他說對了的人**。

## 提案

### 標題長什麼樣

> **我把 580 檔台股跟 0050 一支一支比過:只有 30.7% 贏。而贏的那些,中位數要你套牢 7 年。**

> **台股中位數賺 572%——但 95% 的股票腰斬過。那 572% 是給誰的?**

> **「1200% 報酬的人只存在於回測資料」——一位觀眾這樣說。我用 582 檔資料驗證他對不對。**

三個都不含任何個股代號。**這是刻意的**:個股體檢是圖書館層(搜尋 51% 分鐘,引擎,不動);
旗艦是**橫斷面**層,它的鉤子是「全市場」不是「某一檔」。

### 為什麼只有我們做得出來

- **582 檔已經算完的完整長期回測**(含息還原、最大回撤、最長套牢、與 0050 同期對決),
  而且是**同一份體檢表跑到底**——這是 1,925 檔那個苦工的**唯一真正產出**,
  而我們到今天為止只把它拆成 1,925 支沒人看的小片。
- 別人講「台積電抱 20 年賺幾倍」;**只有我們能講「580 檔一起看,長什麼樣」**。
- 而且它**自帶誠實**:結論對我們自己的產品不利(大部分個股輸給 0050),
  那正是這個頻道的差異化(不喊單、真回測),也是唯一能回應
  「你亂分析 不專業」「完全沒內容」那類指控的東西。

### 第一支做哪個題目

**《抱得住嗎:582 檔台股的真實代價》**

結構(刻意不是個股體檢那五段):
1. **開場即結論**:582 檔中位數賺 572%,而中位數腰斬 73.8%、套牢 7.1 年。
2. **那位觀眾的原話**逐字唸出來,承認他說對了。
3. **拆給看**:95.2% 腰斬過 / 30.9% 套牢十年以上 / 只有 30.7% 贏 0050。
4. **反轉**:所以「選對股票」不是問題,**「抱得住」才是**。而抱不住的人買 0050 也一樣抱不住。
5. **不給建議**,給位置:你自己看你能不能忍 7 年。

### 🔴 它失敗的話,我們多久會知道

**7 天,判準三條,任一條沒過就是失敗:**

| 判準 | 門檻 | 為什麼可信 |
|---|---|---|
| **觀看分鐘/支** | ≥ **1,000**(約長片中位 335.9 的 3 倍) | 全母體可算,不受 Top-200 截斷影響 |
| **RELATED_VIDEO 佔比** | 該片 ≥ **10%**(全頻道現況 3.0%) | 它是單位價值最高的來源(2.57 分鐘/觀看,比搜尋高 69%),而旗艦的假設就是「看完想看下一支」 |
| **留言** | ≥ **3 則觀眾留言**(全頻道八週共 33 則 = 每支 0.3) | 留言當**捕捉器**不當率;有人願意吵就是它有觀點 |

⚠️ **不准用完播率驗**:片長 vs 完播率 r = −0.531,而旗艦片會比體檢片長 ⇒
第一個顯著結果會是長度假象。

**7 天沒過三條裡的任何一條 → 停,不做第二支。** 一支的成本是一天的產能,
而繼續做 1,925 支模板片的成本是我們已經付了三個月的那個。

## 附:我要推翻的那條記憶

`yt-retention-is-audience-not-content`(「留存由觀眾來源決定,非內容」,三次獨立重現)
——**那三次的母體裡每一支片都是同一個模板**。它分不出「內容不影響留存」和
「我們的內容從來沒變過」。

而今天的量測給了直接證據:**18/20 支沒有收束句、3/20 才講到公司在做什麼**——
內容不是「沒有變異」,是**在同樣的地方一起壞掉**。

⇒ **在一個沒有變異的樣本上做的結論,不能拿來當「內容不是槓桿」的理由。**
這支旗艦片就是那個變異。它同時是提案,也是那條記憶的檢定。
