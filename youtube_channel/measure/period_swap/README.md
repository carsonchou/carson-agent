# 期間偷換量尺(四代)

報告見 `docs/ops/2026-09-11_期間偷換_督導獨立複驗.md`。

**只有 `04_matched_pair_ruler.py` 是有效的。** 01~03 是被報廢的三代,
留著是因為每一支的 docstring 記著它為什麼錯——刪掉的話下一個人會再造一次同樣的錯尺。

| 檔 | 判準 | 為什麼廢 |
|---|---|---|
| 01_arith_ruler | 0050 的 n vs **片名年數** | 量到設計(三方比較固定十年共同起點),不是缺陷 |
| 02_in_sentence_ruler | 算術不符 且 **同句**沒寫期間 | 量到規則ⓜ-1 的字面,不是傷害 |
| 03_window_ruler | 期間宣告可跨句繼承 | 答案由視窗長度決定(W=3 給 7.7%、W=10 給 0.6%) |
| **04_matched_pair_ruler** | **0050 的 n vs 同片鄰近個股的 n** | **在用** |

## 跑之前先看兩件事

1. 04 會先跑 **13 項中文數字解析單元測試**,不過就 exit —— 這是刻意的。
   第三代曾因漏「千」把「百分之三千九百六十七點四」讀成 3%,而**七支對照全部矇對**。
2. 對照有十支:九支陰性(全部手開過原檔)+ 一支陽性(眾達-KY 4977,由主頻道線
   用另一種方法獨立判定)。**對照不全過就不准報數字**,腳本自己會擋。

陰性對照裡的力成 6239 / 合晶 6182 / 昇達科 3491 / 台光電 2383 / 奇鋐 3017 / 旺矽 6223
是**專門挑來踩已知弱點的**(個股數字帶「千」、期間宣告在 7~9 句之前、
結構化欄位版型)。加新規則前先確認這六支還是「無害」。

## 已知射程限制

- 只看「同一段裡同時給總報酬與年化」的比較;只給單一數字的比較看不見 ⇒ **報的是下界**。
- 「n 對得上」只證明期間**長度**相同,不證明**起點**相同。
- 讀的是 `output/*.voice.txt` 的**今日磁碟版本**,不等於當初發布的那一版。
