## 1. 專案與用途(Project & use case)
**你的 API client 在做什麼**:
> 量化阿森（Carson Quant）是一個繁體中文的量化交易／投資「避雷」教育頻道。我們用 YouTube Data API 上傳**自製原創**的教學短片與長片，並管理其中繼資料與播放清單、讀取自家頻道分析數據以改進內容。每支影片都是原創腳本、原創回測數據分析與原創旁白，非搬運、非他人內容再上傳。

**用途類別**：Upload & manage our own original educational content。

## 2. 使用哪些 API 方法、為什麼(Which methods & why)
| 方法 | 用途 | 為何需要 |
|---|---|---|
| `videos.insert` | 上傳每日自製教學影片 | 頻道核心；每支 1600 units，量大 |
| `videos.update` | 設定/更新標題、描述、標籤、隱私 | 發布排程、內容維護 |
| `playlistItems.insert` / `playlists.*` | 把影片整理進主題播放清單(系列連看) | 提升觀眾體驗與可搜尋性 |
| `search.list` / `videos.list` | 對照自家已發布影片避免重複上傳、讀狀態 | 去重、對帳 |
| （Analytics API）自家頻道分析 | 讀完播率/觀看以改進內容 | 只讀自己頻道數據 |

## 3. 為什麼需要更高配額(Justification)
> 我們每日發布約 8–12 支**原創**教育短片與長片。單支上傳 `videos.insert` 就要 1,600 units，加上中繼資料更新與播放清單管理，穩定的日常發布已超過預設 10,000 units/日的配額，導致部分當日內容無法上架。申請提高配額以支持穩定的每日原創教育內容發布。

**建議申請額度**：具體填你要的(例如 50,000–100,000 units/日；夠發 ~30–60 支上傳的空間)。

## 4. 合規聲明(Compliance — 據實填)
- **內容原創性**：每支影片為原創製作（原創腳本、原創回測/數據分析、原創旁白與視覺），符合 YouTube 原創內容標準；不搬運、不再上傳他人內容。
- **符合政策**：遵守 YouTube API Services Terms of Service 與 Developer Policies；不濫用 API、不刷量、不操縱互動。
- **內容誠信**：教育性質，不提供投資建議、不喊單、不報明牌、不保證收益；回測內容明確標示為歷史回測、不代表未來。
- **資料使用**：只讀取與管理**自己頻道**的資料；不儲存/散布其他使用者資料。
- **自動化揭露(據實)**：內容製作與上傳流程有自動化輔助，但每支影片為原創且經品質與誠信守門（低分不發、禁重複洗版標題、禁捏造績效數字）。
