Privacy Policy

Carson Quant (量化阿森) — YouTube channel automation
Last updated: 2026-08-30

This policy describes how the private automation software operated by the owner of the YouTube channel Carson Quant (UCqP5JQXlQR5ZDLtEiBt4kLA) handles data obtained through the YouTube API Services.

本政策說明「量化阿森 Carson Quant」頻道所使用的自動化程式, 如何處理透過 YouTube API 取得的資料。

1. Who we are / 我們是誰

This software is a private, internal-use tool operated by an individual creator to manage his own YouTube channel. It is not a public service: it has no user accounts, no sign-up, and it does not act on behalf of any third party. The only Google account that authorises it is the channel owner's own account.

這是個人創作者管理自有頻道的內部工具,不對外提供服務、沒有使用者註冊, 唯一授權的 Google 帳號就是頻道擁有者本人。

2. What data we access / 我們取用哪些資料

  • Our own channel's content and metadata — video titles, descriptions, thumbnails, captions, playlists, and upload status. Obtained via videos, captions, thumbnails, playlistItems and channelSections endpoints.
  • Our own channel's analytics — aggregate view counts, watch time, average view duration, traffic sources and subscriber totals, via the YouTube Analytics API. This data is aggregate and does not identify individual viewers.
  • Public comments left on our own videos — comment text, comment ID, and the commenter's public display name and channel ID, via commentThreads and comments. This is used solely to read and reply to comments on our own videos.
  • Public metadata of other public YouTube videos — titles and public view counts, via search and videos, used for our own content planning research.

We do not access any private data belonging to other users, and we do not use any method other than the official YouTube API to obtain data (no scraping).

我們不取用任何其他使用者的私人資料,也不使用官方 API 以外的任何方式取得資料 (不做爬蟲)。

3. What we store, and for how long / 我們儲存什麼、存多久

  • Third-party data (public metadata of other creators' videos, and comment records) is stored only on the operator's own computer and is automatically deleted after 25 days by a scheduled job, which is within the 30-day limit in section III.E.4.d of the YouTube API Services Developer Policies.
  • Commenter identity is not retained. Display names and channel IDs are read into memory to decide whether a comment still needs a reply, but the files kept on disk contain only comment IDs and video IDs — no names, no channel IDs, no profile images.
  • Our own channel's data (our videos and our own aggregate analytics) is our own content and is retained for long-term growth analysis.
  • Nothing is stored on any public server. There is no database accessible from the internet.

他人資料只存在操作者自己的電腦,由排程於 25 天後自動刪除 (政策上限為 30 天,留 5 天安全邊際)。留言者的名稱與頻道 ID 不落檔, 磁碟上保存的只有留言 ID 與影片 ID。

4. What we never do / 我們絕不做的事

  • We never sell, rent, or share any data obtained from the YouTube API with any third party.
  • We never use the API to generate artificial engagement — no automated likes, no artificial views, no subscriber inflation, no automated comments on other creators' videos.
  • We never store or process YouTube user data for advertising or profiling.
  • We never ask any other person to authorise this software with their Google account.

我們絕不販售或分享 API 取得的任何資料;絕不用 API 製造虛假互動(刷讚/刷觀看/ 刷訂閱/對他人影片自動留言);絕不將 YouTube 使用者資料用於廣告或側寫。

5. Third-party services / 第三方服務

Video scripts and thumbnails are generated with the help of large-language-model (LLM) APIs, and narration is synthesised with text-to-speech. Two of these calls involve viewer data, and we describe them precisely:

  • Comment reply drafting and classification. When we prepare a reply to a comment left on one of our own videos, the text of that comment is sent to an LLM provider so that a draft reply can be written and the comment classified (question / thanks / other). The commenter's display name, channel ID and profile image are never sent — only the comment text itself.
  • Everything else — topic briefs, titles, and Taiwan stock market price data derived from public market sources — contains no YouTube user data at all.

These providers process the text to return a response and we do not authorise them to use it for any other purpose. If you would prefer that your comment is not processed this way, delete your comment on YouTube or contact us at the address below.

腳本與縮圖會用到大型語言模型 API、旁白使用語音合成。其中有兩處會碰到觀眾資料, 如實說明:要對我們自己影片下的留言草擬回覆、或判斷留言類型時,會把「留言文字本身」 送給 LLM 供應商;留言者的顯示名稱、頻道 ID 與頭像一律不送。 其餘送出的內容(選題說明、標題、來自公開市場來源的台股行情)完全不含 YouTube 使用者資料。 若你不希望留言被這樣處理,可以在 YouTube 上刪除留言,或以下方信箱聯絡我們。

6. Data deletion and access requests / 刪除與查詢

Because we do not retain identifying information about viewers, there is normally nothing to delete. If you have commented on one of our videos and would like the record of that comment removed from our local files, or you have any question about this policy, contact us at the address below and we will action it within 30 days. You can also delete your own comment directly on YouTube at any time, which removes it from our systems on the next refresh.

由於我們不保留觀眾的識別資訊,通常沒有可刪除的內容。 若你曾在我們的影片留言、希望我們刪除本機的該筆紀錄,或對本政策有任何疑問, 請以下方信箱聯絡,我們會在 30 天內處理。你也可以隨時在 YouTube 上自行刪除留言。
