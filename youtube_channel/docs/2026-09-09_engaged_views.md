# 有效觀看次數(engagedViews)實測 —— 2026-09-09

Carson 問「有效觀看次數」。YouTube Analytics 有官方對應指標 `engagedViews`,本檔是實測結果。

憑證:`token_analytics.json`(⚠️ `token_manage.json` 缺 analytics scope,用它一律 403 ——
`scripts/_analytics.py` 現在正是用它,那支是壞的)。

## 🔴 先講一個會讓人做出反決定的陷阱

**`engagedViews` 對長片是 2026-08-27 才開始真的量的。在那之前它等於 `views`。**

證據三條:
1. 08-17~08-26,**五個互不相干的來源同時剛好是 100.0%**(SUBSCRIBER / RELATED_VIDEO /
   NO_LINK_OTHER / PLAYLIST / NOTIFICATION)。真實量測不會五個來源同時落在整數 100.0。
2. **陰性對照:SHORTS 前後 42.4% → 43.5%,沒有動。** Shorts 本來就有這個指標,
   所以「定義改了」講不通 —— 改的話 Shorts 也要動。
3. 掉幅大小和「是不是長片來源」對齊,和流量規模、和來源性質都不對齊
   (EXT_URL 流量成長 3.6 倍而有效率 97.3% → 100.0%,一點沒掉)。

⇒ **任何跨 08-27 的前後比較都是假的。** 只有 08-27 起的數字能用。
⚠️ 這條是本輪推論,不是查證過官方文件的結論 —— 但「不要跨 08-27 比較」這個處置在兩種解釋下都成立。

## 這張表決定什麼

1. **「觀看次數不夠多」這個問題的分母是壞的。** 首頁 feed 供給 45.4% 的觀看,
   卻只換到 17.0% 的分鐘。要衝觀看數,最快的路是再多拿一點首頁 feed,
   而那條路**幾乎不增加有效觀看也不增加分鐘**(而 YPP 算的是分鐘)。
2. **搜尋才是這個頻道的主體**:44.7% 觀看 → 63.6% 分鐘。
3. **RELATED_VIDEO 是唯一同時「高有效率 + 高單位分鐘 + 低量」的來源**:
   2.4% 觀看換到 9.1% 分鐘,單位價值是首頁 feed 的 2.1 倍。這是還沒開的門。
4. ⚠️ 但 RELATED_VIDEO 高有效率**可能只是倖存者偏誤**(能從推薦進來的本來就比較黏),
   不能直接推「把量做大就會保持 85.9%」。先量因果方向再投資源。
