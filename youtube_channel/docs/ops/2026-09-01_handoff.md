## 二、誠信閘門:最終判準與為什麼是這個數

### 背景:舊守門已經失效

`fact_source_guard` 用**全域**事實池(38,231 個數字)比對。實測 pct 子池在 0~200 區間有
20,704 個值、相鄰間距中位 **0.0032**,而嚴容差是 `max(0.25, 值×0.5%)` ≥ 0.25 =
間距的 78 倍 → **池子實質連續,任何百分比都找得到鄰居**。
隨手編的 1234.5% / 777.7% / 88.8% / 42.195% 全部判「有憑據」;隨機 400 個百分比通過率 **100%**。

它不是壞掉,是**慢慢失效**:2026-07 建立時事實庫只有 5 組,擋得住;現在 504 檔 × 13 組
把池子填滿。→ memory `yt-fact-guard-pool-saturation`

### 新閘門 `_long_corrupt_number`(produce_batch.py)

**判準**:同一句話裡至少 2 個百分比,其中 **≥2 個對得上該股自己的事實**、而 **≥1 個對不上**。

**為什麼是「≥2 對得上」而不是 1**:一個對得上可能是巧合(池子密),兩個對得上代表
「這句話正在抄事實」,那麼第三個對不上就是抄壞了,不是修辭。實例:

```
信昌電6173  旁白 總報酬 794.7% / 年化 29.2% / 回撤 74%
            事實 總報酬 1194.7% / 年化 29.2% / 回撤 -74.0%
```

**兩道放行(偽陽性全落在這兩類,是抽驗調出來的不是設計出來的)**:
1. 假設/舉例語境整句跳過 — `假設 舉例 例如 比方 以為 想像 打個比方 如果你 換算 相當於 意思是 也就是說`
2. 「超過/不到 + 概數」— 池裡有值在正確那一側且差距 ≤ `max(15, v×0.25)` 就算溯源到

**調校過程(命中數)**:12 → (加放行①) 3 → (加放行②) 3,但成員換了一支。

## 六、當天沒做成的事(不要重做)

1. **片長壓回 9~11 分甜蜜點** — 試了三種 prompt 寫法都失敗:

   **結論:模型遵守「幾段」這種可數的約束,不遵守字數區間。** 要壓長度得用確定性後處理,不是 prompt。

   中文數字解析常錯;88 處樣本裡真正不一致的是 0 處。

## 七、量測方法的坑(踩過才寫的)

- **不能比對阿拉伯數字**:旁白一律中文唸法。比主題關鍵詞,或用 `_cn_num` 轉。
- **主題關鍵詞也會漏報**:`annual_extremes` 旁白寫「在二零零八年…」不寫「最慘一年」。
- **`ya.video_stats()` 被截斷 200 支**(Analytics 對 `dimensions=video&sort=-views` 硬上限,
  `limit` 調到 1200 仍只回 200)。全量要用 `filters=video==` 批次(≤200/批)。
  **我用截斷樣本算過一次門檻,而 r(觀看數,留存)=-0.406 → 樣本偏向「看起來像輸家」那端。**
- **片齡是致命混淆變數**:按發布量分組看「每支觀看」會得到「9-12 支/日崩塌到 3 次觀看」,
  控制片齡後發現那 31 支**全是 61 天以上的舊時代片**,同齡的 1-4 支/日也只有 4 次。
- **寫入後立刻回讀是快取**:刪留言後回讀仍顯示 2 則,等 25 秒才變 1 則。
- **fail-open 的防護壞掉時沒有聲音**:`ch3_lab` 路徑寫錯 → 檔案不存在 → 回 0 → 防護等於沒裝
  而且不報錯。**驗證不能只驗「不炸」,要驗真值**(自檢「應該回 3 卻回 0」才抓到)。
