## ① 說明欄的事實宣稱

### 1a 那句「論文連結在上面」— 成立,但有一個已知的斷點

它宣稱什麼:`desc_for()` 依「幾條 cite 真的帶連結」三選一。五支全部走到
`linked == len(cites)` 這一支,印的是 **"The papers are linked above."**

實測(跑真的 `build_meta()`):五支**各 3 條 cite 行,3 條都帶 `https://`**,
所以那句話印出來是 "The papers are linked above."

- 全部是 `https://doi.org/10.…` 形式,無重複、無 `doi.org/doi.org` 雙前綴。
- facts.json 的 DOI vs 說明欄印出的 DOI:**漏 0 / 多 0**(五支皆是)。

**陰性對照(直接餵 `desc_for()`)**

| 餵進去的 cites | 印出來 |
|---|---|
| 3 條全帶連結 | The papers are linked above. |
| 2 條全帶連結 | **Both** papers are linked above. |
| 3 條裡只有 2 條帶 | The papers **with a DOI** are linked above; the rest are named in full… |
| 0 條帶連結 | **The sources are named above.** |

**突變釘(比陰性對照更承重)**:把 `_doi_url()` 改壞成舊的裸 `doi:`,**再跑真的 `build_meta()`**
→ 五支**全部翻面**成 "The sources are named above."(5/5);把函式放回去,五支說明欄**逐字回到原狀**。
⇒ 那句話不是常數,而且產線那條路真的經過 `_doi_url()`。少了這一格,「5/5 印對」和
「那段判斷根本沒在跑」分不開。

**15 條 URL 真的去解**(只問 doi.org 第一跳,不跟隨):**15/15 已註冊,全部 302 轉到出版商**。

> ⚠️ 儀器的坑,記下來:第一版跟隨轉址,量到 **11/15 是 403**,差一點被我判成 FAIL。
> 403 是出版商擋 script UA,不是連結壞掉。分辨的辦法是**只看 doi.org 那一跳**:
> 沒註冊的 DOI 停在 doi.org 回 404 且不發 Location。是陰性對照救回來的,不是我謹慎。

陰性對照:不存在的 DOI → 404 無 Location。陽性對照:一條不在這五支裡的真 DOI(Dekker 2014)→ 302 → nature.com。

### 🔴 1b `reel_if_then_plans` 的 URL 含括號 —— 這句話對它可能仍為假

```
https://doi.org/10.1016/S0065-2601(06)38002-1
```

15 條裡只有這一條含 `(` `)`。自動連結器普遍在 `(` 或 `)` 斷句。

**可測的那一半我測了**:截在 `(` 之前剩下 `https://doi.org/10.1016/S0065-2601` → **404,doi.org 不轉址**。
⇒ 若 YouTube 真的在那裡斷,觀眾點到的是一個死連結,而 "The papers are linked above." 對這一支就**又變成假的**。

**我測不到的那一半**:YouTube 實際怎麼斷 —— 那要真的發出去才看得到。**這一格是靜態推論。**

這跟上一輪擋下發布的是**同一類缺陷**(說明欄宣稱有連結、實際點不到),而
「開頭是不是 https://」那套檢查**完全抓不到它**。
最小修法:`_doi_url()` 把 `(` `)` 百分號編碼成 `%28` `%29`(doi.org 接受,且不含斷句字元)。

### 🔴 1c 兩處對觀眾的宣稱比事實庫強

**(i) `focus_techniques`:**「When you cannot focus, it is usually not willpower. It is the room.」

- 「**usually**」是一個盛行率宣稱 —— 「注意力失敗多半來自環境而非意志力」。
- facts.json 的 evidence 只有效果量:`phone_eta2_exp1 0.014`、`phone_eta2_exp2 0.026`、
  `todo_list_d 0.63`、`vigilance_break_f 0.89`。**沒有任何一個在量盛行率。**
- 更尖銳的是:它自己的 `display_only_why` 寫著「Both effects were small」。
  說明欄說環境是**通常**的原因,而它的旗艦環境證據 η² = 0.014 / 0.026,**是小的**。
- 這句話**同時在畫面上**(t≈5 秒的開場卡,已逐幀看過),不只在說明欄。

**(ii) `pomodoro`:**說明欄寫「**One trial tested that exact recipe**…」

- 影片裡是「trials on the exact recipe / **that our search found** / 1」(t≈30 秒逐幀看過)。
- facts.json 的 `display_only_why` 明寫:「旁白唸的是『In our own search, we found one』」。
- ⇒ **限定語是刻意設計進去的,而說明欄把它拿掉了。**
  「我們的搜尋只找到一篇」和「只有一篇」是兩件不同強度的事;後者是一個文獻完整性宣稱。

這兩處都屬於 memory `yt-integrity-methodology-claims-blindspot` 點名的類別:
守門抓「沒憑據的數字」,對「usually / 只有一篇」這種**方法論與量級宣稱**是盲的。
兩處都**不是數字錯**,所以逐字數字對帳(下表)全過也不會叫。
