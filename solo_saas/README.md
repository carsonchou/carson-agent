# numerus —— 財經文字的「同段可驗算」檢查

候選 1 的可跑原型。一句話講它做什麼:

> 一個金額,如果和作者**在同一句話裡自己給的**本金、報酬率、年數怎麼算都對不起來,
> 那不是查無來源,是編的。

它不查任何外部資料庫,不連網,不需要金鑰。輸入是文字,輸出是三種判決。

```
python cli.py <檔案或目錄> [--ext .voice.txt] [--quiet] [--gate]
python tests/run_corpus.py          # 手寫語料回歸(23 條)
python tests/mutation.py            # 靈敏度突變測試(需要真語料目錄)
```

---

## 為什麼不做成「比對事實池」

上一代的守門是拿稿子裡的數字去比對一個全域事實池。它有兩個結構性的死法,
兩個都已經實測過(`youtube_channel/docs/fact_pool_unit_blindspot.md`):

1. **規模詛咒**:池子越大越容易撞到鄰居。「多賺 37 萬」撞上池裡某個「37.1%」,
   於是守門替一個編出來的數字**背書**。池子越完整,這個病越重。
2. **裸金額偵測器誤殺 8/21 = 38%**:人數(「一百二十萬人」)、外幣新聞、
   在拆穿別人的宣稱、合法的成數算術,全被當成造假。

所以這支工具**完全不碰事實池**,判準改成文本內部的算術一致性。
代價是它管不到「數字有沒有出處」,只管得到「數字自己圓不圓得起來」。
這個邊界要講清楚:**它不是誠信守門的替代品,是誠信守門缺的那一塊。**

## 三種判決

| 判決 | 意思 | 進 exit code 嗎 |
|---|---|---|
| `CONTRADICTED` | 算得出來,而且怎麼算都對不上 —— **有證明的指控** | `--gate` 時 exit 1 |
| `BARE` | 同段沒給足夠的東西,觀眾無法自行驗算 —— **誠實的「我不知道」** | 🔴 永遠不影響 |
| `CONSISTENT` | 對得上至少一種合理算法 | 否 |

### 🔴 為什麼 BARE 不能當閘門

`cli.py` 的 docstring 指著這一節。理由有三層,由淺到深:

**第一層:數量。** 掃 922 支正式旁白,BARE 有 **897** 條、CONTRADICTED 只有 **1** 條。
把 BARE 當閘門等於停產。

**第二層:BARE 不是缺陷,是這支工具的認知狀態。**
「他在廣告裡號稱三年就能滾到千萬」是在**拆穿別人**;
「比致伸多賺了三十四萬兩千元」的對照組數字在**別句**;
「投入一百萬,過程中一度只剩三十四萬」的低點在路徑中途,期末數字算不出它。
這三句沒有一句有錯。BARE 說的是「我算不出來」,主詞是工具,不是稿子。
把它當閘門,就是把**我的無知**寫成**作者的罪狀** ——
這正是 memory `read-the-sibling-tool-first` 記的那個病:把自己的認知狀態當成世界的狀態。

**第三層:它會壞得很安靜。** 一個 90% 觸發率的閘門,唯一的活路是被繞過或被關掉,
而繞過之後沒有任何錯誤訊號。memory `yt-period-swap-integrity` 已經付過這個學費:
我加的閘門讓產線停了兩天。**閘門的成本要用接近真實觸發率去估。**

要拿 BARE 做事的話,它適合當**寫作提示**(「這句話觀眾驗不了,要不要補一句本金?」),
不適合當出廠條件。

## 🔴 這支工具最重要的一課:12/12 全過的同時,31/32 是誤指控

第 3 輪的時候,手寫語料 **12/12 全過**,而真語料上 32 個指控裡 **31 個是我冤枉作者的**。

成因就是 memory `gate-verification-population`:
**驗閘門的母體必須是「會經過它的全部片」**,而我當時的母體是我自己想得到的 12 句話。
手寫語料只證明了「我想到的情況它會過」,證不了「我沒想到的情況它不會亂咬」。

所以第 5 輪和第 8 輪的兩次倒退不是意外,是這個方法**該有的樣子** ——
每一次修法都必須回全母體重量一次,而且每個新指控都要手工核對。
`tests/corpus.json` 裡的 `real-*` 那 11 條,就是這兩次倒退抓到的真句子,逐字釘下來的。

### 但「不冤枉」還有一個更難看的解釋:它乾脆不叫了

CONTRADICTED 從 32 掉到 1,可以是修好了,也可以是**閘門啞了**。
CONSISTENT 從 64 升到 209 證明它認得出「對的」,但證不了它認得出「錯的」。

所以有 `tests/mutation.py`:把真語料裡每一條判成 CONSISTENT 的宣稱,
**金額改成錯的**(×2.73,刻意避開整數倍以免撞上「翻 N 倍」的合法讀法),看它叫不叫。

```
陽性 注入 207 條錯誤金額:抓到 178 → 靈敏度 86.0%
       漏掉 BARE       26 條(逃生門吞掉,見下方天花板)
       漏掉 CONSISTENT  3 條(容差 25% + 候選算式太寬,撞上了別的算法)
陰性 換寫法不換值 207 條:誤指控 0 → 誤報率 0.0%
```

靈敏度是靠這支測出來的:一開始是 **78.9%**,兩次收窄逃生門之後到 **84.2%**。
最後的 86.0% 有一半功勞屬於**修好量尺自己** ——
陰性對照抓到我的替換函式打錯了字串(「七十八萬五千元」是「一百七十八萬五千元」的子字串),
那 3 個「誤指控」根本不是工具的錯,是尺刻歪了。
**陰性對照的用處就在這裡:它驗的是測試工具本身。**

## 已知天花板(不是待修的 bug,是這個方法的邊界)

1. **回撤的底會在句中被換掉。**
   「投入一百萬…光是 2008 年就暴跌 65%,等於你的**兩百萬**瞬間剩下七十萬」——
   200×0.35=70,稿子是對的,而工具把本金釘在句首的一百萬。已改成閉嘴,不指控。
2. **對照組的數字在別句。** 「比致伸多賺三十四萬兩千元」的另一腿抽不到 ⇒ BARE。
3. **路徑中途的低點。** 「一度」「谷底」「過程中」說不出在哪一天,只有回撤幅度算得出來。
4. **「腰斬」是不定值。** 腰斬再腰斬是 75%、三次腰斬是 87.5%。
   第 5 輪我補了一條「腰斬=50%」,淨生 11 個新冤枉,已整條移除。
5. **容差 25% 是刻意放寬的**,而它有代價:突變測試裡 3 條錯誤金額因此撞上了別的候選算式。
   這是「寧可放過不要冤枉」這個選擇的**已量化**成本,不是疏忽。
6. **只驗金額,不驗「率與率之間」。**
   實測有稿子同句寫「總報酬 712%、年化 23.3%、期間 15.3 年」——
   712% 換算年化是 14.7%,而 1.233^15.3 = 24.6 倍,三個數字互不相容。
   這是**另一種**編造,現在的工具看不見。這是 v2 最值得做的一條。

## 三個母體(2026-09-09 量完,`gate-verification-population`)

三個要**一起看**才有意義:①說這次多擋誰、②說明天少發多少、③說原本擋得住的有沒有被放掉。

### ① 新增被擋 = 0 支 / 817(0.00%)

🔴 **①是改動的差集,不是閘門的定義域。** 跑一次有閘門的、數它擋幾支,量到的是②不是①。
所以 `tests/measure_delta.py` 拿**同一批輸入**跑兩次:

| | 口徑 | 結果 |
|---|---|---|
| 無閘門 | 產線現在的決定(稿子落在 `output/` 根目錄) | 817 支放行 |
| 有閘門 | 現在的決定 **AND** numerus 不判 CONTRADICTED | 817 支放行 |
| **①** | 前者 ∖ 後者 | **0 支** |

唯一那支 CONTRADICTED(品安 8088,把 739.8 萬寫成 6,398 萬)落在 `output/_bad_leak/` ——
**已經不在出貨路徑上**,接上 numerus 不會改變它的命運,所以不算進①。
(⚠️ 原本這裡寫「已經被 prompt 洩漏閘門擋掉了」。查證後**這個前提不成立** ——
全 repo 沒有程式碼會把檔案搬進 `_bad_leak/`,是人搬的,理由和數字錯誤無關。
詳見 [GATE_UPGRADE_CRITERIA.md](GATE_UPGRADE_CRITERIA.md)。)

**「0」自己不能當證據** —— 得先證明這支量尺量得出非零。陽性對照(用真案例,不用合成 fixture,
`gate-blind-while-target-evolves`):把那支真的 CONTRADICTED 稿**複製到沙箱語料的根目錄**
→ ① 變 **1/2**;同一份稿放進沙箱的隔離子目錄 → 正確地**不**算進①。量尺會動,0 是真讀數。
(這些工具不搬動任何產線檔案 —— solo_saas 裡沒有一行會移動 `output/` 下的東西。)

⚠️ 但 0 有一個天花板:它是**對已經被上游閘門洗過一輪的稿子**量的。
上游哪天鬆掉,①會跟著變 —— **①是快照不是常數**,接上去之後要定期重量。

### ② 定義域 = 全部會經過它的 922 支

CONTRADICTED 1 / BARE 897 / CONSISTENT 209。
🔴 **897/922 的 BARE 就是「BARE 不能當閘門」的全部理由**:當閘門等於停產。
(見上面「為什麼 BARE 不能當閘門」。)

### ③ 反方向被放掉的 = 突變測試,靈敏度 86.0%(178/207)

把語料裡每一條 CONSISTENT 的金額乘 2.73 再餵回去,看它哭不哭。29 條沒哭 = 已知的漏網形狀。
陰性對照(同值換阿拉伯數字寫法)**0/207** 誤報 —— 這條一開始是 3/207,查出來是**量尺自己的
子字串 bug**(「七十八萬五千元」是「一百七十八萬五千元」的子字串),不是工具誤判。

### 合起來怎麼讀

接上這道閘門:今天多擋 **0** 支、明天預期少發 **0** 支(①=0 ⇒ 產能零衝擊)、
反方向抓得到 **86%** 的注入錯誤。⚠️ 但①=0 同時也是最弱的那句話 ——
**一道今天擋不到任何東西的閘門,它的價值全押在未來**,而那正是 `yt-period-swap-integrity`
(我上一次估閘門成本用 r³ 而真實觸發率差 11~274 倍)警告過的地方:成本要用**接近真實觸發率**估。
①=0 是觸發率的一次觀測,不是它的上界。

## 現在的接法:只報告不阻斷(2026-09-09 總督導裁示)

`--gate` 存在但**不掛上產線**。`watch.py` 每次掃描把 CONTRADICTED 寫進 `ledger.json`,
永遠 exit 0,不影響任何流程。

為什麼不直接接成阻斷 —— 因為①=0 只證明了「安全」,沒證明「有用」:
**全母體唯一那支 CONTRADICTED 已經不在出貨路徑上,所以 numerus 的邊際貢獻還沒被量到。**
(「還沒被量到」不是「證明為 0」,兩者也都不是「已證明有用」。)

升級成阻斷的三個條件寫在 **[GATE_UPGRADE_CRITERIA.md](GATE_UPGRADE_CRITERIA.md)**,
而且是**現在**寫的(在它抓到任何獨立真陽性之前)。`python watch.py --status` 是那份判準的執行版本。

🔴 判準裡有一個會恆真的坑,已經堵掉並驗過:**沒有人核對時,「誤報 0」會自動成立。**
所以未核對的 CONTRADICTED 一律讓條件 2 **不成立**。兩格對照都跑過:
合成一支「放行區的真陽性」→ `--status` 說得出「可以進入升級討論」;
再加一支誤指控 → 條件 2 單獨否決。**兩個條件都能各自翻面,所以真帳本上的「不可升級」是真讀數。**

🔴 獨立驗證(fresh context,`docs/ops/dispatch.md` §6)打穿三個洞,都已修並各自帶對照:

| 洞 | 症狀 | 修法 | 對照 |
|----|------|------|------|
| **「獨立性」是可變的,判決是黏的** | 每次掃描用檔案**當下**目錄覆寫判準欄位,而 `human_verdict` 是黏的 ⇒ 把已隔離、已判真陽性的稿子還原回 `output/` 根目錄,`--status` 立刻說「可以升級」——用的正是判準寫明「那支不算」的稿子 | 拆成 `first_context`(立了不改,判準只認它)/ `current_context`(會變,只印一行 ⚠️) | A-3:沙箱裡把它從 `_bad_leak/` **搬**回根目錄,仍判「不可升級」並印出位移警告 |
| **「永遠 exit 0」是假的** | `numerus_watch.py` 的旗標迴圈和寫檔在 try/except **外面**:輸出目錄不存在 → `FileNotFoundError`;帳本有缺欄位的舊紀錄 → `KeyError` | 整段包進 try、欄位改 `.get()`、`mkdir(parents=True)` | E/F:兩個原本確定 exit 1 的輸入,現在都 exit 0 |

另外堵掉的:帳本檔**不存在**時原本讀成空帳本、一路印出「條件 2 成立」;現在先說

TTS 邊產邊寫在最終路徑)會製造永久假陽性 —— 加了 10 分鐘靜置窗,跳過幾支會印出來。

# selfcontra —— 同稿自相矛盾(2026-09-10 新增)

上面那張「已知天花板」的第 6 條(只驗金額、不驗率與率)開了一半。
`numerus/selfcontra.py` 走的是另一條路:**不算式子,只問同一份稿子有沒有講兩套。**

> 一支稿子對**同一標的、同一指標、同一策略**給出兩個對不起來的值。

```
python selfcontra_cli.py <檔案或目錄> [--ext .voice.txt] [--tol 1.0]
                          [--since YYYY-MM-DD] [--json 輸出.json]
python tests/test_selfcontra.py     # 真案例對照(陽 5/陰 16/已知誤報 3/已知錯理由 1),不見檔就 FAIL
```

**它和 numerus 主線的差別**:numerus 問「這個數字自己圓不圓得起來」,
需要同句有本金/年數才算得動,所以 897/922 是 BARE。
selfcontra 不需要任何算式,只要同一稿出現兩個同義位置的讀數就能判,
定義域因此完全不同(0050 年化:259/923)。**兩支互補,不重疊。**

**為什麼事實池抓不到它**:池裡 38,231 個數字在 0~200 區間實質連續
(memory `yt-fact-guard-pool-saturation`),**兩個互相矛盾的值各自都能在池裡找到靠山**。
只查文件內部一致性的檢查,結構上免疫於那個失效模式。

| 定義域 | 259 | 抽得出至少一個 0050 年化讀數的 |

| (a) 叫對、理由對 | **12** | **要引用就引這個:12/25 = 48%** |
| (b) 叫對、理由錯 | 1 | 稿子真的矛盾,但偵測器配的是已揭露的不同窗 |
| (c) 誤報 | 12 | 兩個窗都揭露了,被我湊成一對 |

🔴 **這裡原本寫「精確率 22/25 = 88%」,那個數字是錯的,不要再引用。**
錯法是**驗錯東西**:當時 `Contradiction` 沒有留「它憑哪兩個數字叫的」,
所以 25 支手工檢查驗的是**判決**(稿子矛不矛盾),不是**理由**(那一對成不成立),
而**判決和理由會分開失效**(memory `verification-claims-in-commit-messages`:
「我驗的是資料而背書的是論證」)。2026-09-10 由總督導查出一支活的反例。
現在 `Contradiction` 帶 `low`/`high`,CLI 印「憑↓/憑↑」,JSON 有 `trigger` 欄位。

⚠️ **「被標記率」和「精確率」是兩個不同的數,不要互相代入**
(主頻道線的 31.1% 就被這樣誤讀過一次)。
⚠️ **召回率未知** —— 沒有獨立標註集,只知道 5 個真案例陽性對照都會叫。
這不等於「沒有漏的」;已知**至少漏一句**(見下)。

**還在發生,不是存量**:07 → 7/68 = 10.3%、08 → 12/119 = 10.1%、09 → 6/72 = 8.3%,
三個月持平。九月最新那支 `L_ALL-IN0050十年多賺一倍…` 的真矛盾是
**同一個十年窗的 736.9% vs 761.2%**(稿子第 8 段自己寫「同樣是近十年的資料」),
而偵測器抓到的是十年 vs 十三年那組已揭露的窗 —— 判決對、理由錯。
🔴 更糟的是 761.2 那一句**抽不出來**:它講「一次性 All-in」卻整句沒提 0050,
被實體邊界擋掉。**真正的理由偵測器看不見。**

## 已知的誤報類別(唯一活著的那一類)

12 支誤報**全部是同一型:稿子有揭露兩個不同的回測窗**,
而且分界線正好是內容家族:12 支誤報全是 **ETF 對決/大盤題**,
每一句「同期」的**上一句都剛宣告過期間**;12 支真陽性全是**個股體檢**,
罐頭句「同期買進持有 0050」**通篇沒宣告過任何期間**。
⇒ 真正的判別器是「上一句有沒有替這個『同期』宣告期間」,不是「窗一不一樣」。
把期間抽成第四個維度可以吃掉它們,但也會開一個新的漏報方向,**要先有對照再動**
(已評估、未採用,連同算術反推期間的失效方向,見 findings 第 8 節)。
